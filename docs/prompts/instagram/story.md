# 스토리 규칙

스토리는 작은 피드가 아닙니다. 피드는 모르는 사람이 나를 찾는 곳이고, 스토리는 이미 팔로우한 사람이 "이 사람 믿을 만한가"를 정하는 곳입니다. 그리고 **피드 밖에서 링크를 누를 수 있는 유일한 곳**(링크 스티커)이라 블로그로 보내는 핵심 통로입니다.

## 하루 구성 (3~7장)

```
1       시작    오늘 있었던 일. 얼굴이나 손이 나오게
2-3     내용    실제 내용: 과정, 결과, 실수
4       요청    스티커 하나 (투표, 질문, 퀴즈, 링크)
5       마무리  답, 결과, 또는 내일 예고
```

요청은 7장이 아니라 **4장**에. 넘길 때마다 보는 사람이 줄어서, 남아 있는 사람이 보게 해야 합니다.

## 블로그 글로 보내는 스토리 (3장)

```
1   문제    "연말정산 미리보기, 12월 18일에 닫혀요" — 상황 한 줄 + 사진·화면
2   핵심    글의 핵심 하나를 미리 보여 줌 (전부 말하지 않기)
3   링크    링크 스티커 + "정리한 글" 한 마디. 스티커는 화면 가운데
```

- 링크 스티커 문구는 짧게: "전체 정리 보기", "체크리스트 보기"
- 같은 글을 하이라이트에 모아 두면 프로필에서 계속 들어옵니다

## 스티커가 하는 일

| 스티커 | 하는 일 | 쓸 때 |
|---|---|---|
| 투표 | 가장 쉬운 반응 | 정보보다 반응 수가 필요할 때 |
| 질문 | 사람들이 쓰는 말 그대로 모으기 | 콘텐츠 아이디어·궁금증이 필요할 때 |
| 퀴즈 | 틀리게 해서 가르치기 | 흔한 오해가 있을 때 |
| 링크 | 프로필 말고 유일하게 누를 수 있는 곳 | 블로그 글·쿠팡 링크로 보낼 때 |
| 카운트다운 | 마감 알림 구독 | 신청 마감·시즌 시작 |

**질문 스티커가 가장 저평가돼 있습니다.** 받은 답 하나하나가 캡션, 릴스 훅(16번 "받은 질문 그대로"), 다음 글감입니다.

## 규칙

- **첫 장에 얼굴이나 손.** 색 배경에 글자만 있으면 넘깁니다.
- **한 장에 한 내용.**
- **글자는 가운데에**: 1080×1920에서 위 250px, 아래 320px은 프로필 줄·답장 창에 가려집니다.
- **한 사람에게 말하듯.** 스토리는 DM 다음으로 가까운 곳입니다.
- **내 피드 게시물을 말 없이 공유하지 않기.** 가장 무시되는 장입니다. 왜 다시 볼 만한지 한 마디를 붙입니다.
- **쿠팡 링크 스티커**를 쓰면 그 장에 대가성 문구를 작게 넣습니다.
- **DM은 상대가 먼저.** 질문·투표에 반응한 사람에게 답하는 것은 괜찮지만, 반응하지 않은 사람에게 DM을 뿌리면 계정이 제한됩니다.
