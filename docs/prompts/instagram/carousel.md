# 캐러셀(카드뉴스) 규칙

넘겨 보는 게시물입니다. 넘기는 동작 자체가 반응이라 피드에서 가장 오래 머무는 형식이고, 반응하지 않은 사람에게 뒷장부터 다시 보여 주기도 해서 **2장도 표지처럼** 써야 합니다.

## 릴스 대신 캐러셀을 쓸 때

순서가 있고 **다시 읽어야 하는** 내용: 단계, 여러 부분으로 된 틀, 전후 비교, 캡처해 둘 목록. 움직임·얼굴·눈으로 봐야 하는 결과가 있으면 릴스입니다. 주장 하나뿐이면 둘 다 아니고 릴스 훅 하나로 충분합니다.

## 여러 장 카드뉴스 (6~10장)

```
1        표지     훅. 15자 안쪽, 섬네일에서도 읽히는 크기. 그 아래 한 줄 약속
2        이유     왜 중요한지 한 문장. 두 번째 표지 역할이라 설명으로 시작하지 않기
3 ~ N    한 장 한 내용   제목 3~10자 + 본문 40자 안쪽. 문단이 필요하면 두 장으로
N+1      정리     전체를 목록으로. 사람들이 캡처해서 보내는 장
마지막    요청     하나. 저장, 댓글 키워드, 프로필 링크 중 하나
```

최대 20장이지만 20장은 아무도 끝까지 안 읽는 책입니다. 5장 미만이면 넘기기가 시작되지 않습니다.

## 한 장 요약 카드

글 하나를 이미지 한 장으로 요약합니다. 캡처·공유용입니다.

- 제목(15자 안쪽) + 핵심 3~5줄(각 20자 안쪽) + 출처·기준 시점("2026년 기준") + 계정 이름
- 숫자가 핵심이면 숫자를 가장 크게
- 자세한 내용은 "프로필 링크에서 전체 글"로 안내

## 장마다 지킬 것

- **표지가 결과의 80%.** 짧게, 크게.
- **1080×1350(세로 4:5)으로 만들고** 표지 글자는 가장자리 120px 안쪽에. 프로필 격자에서 잘려도 보이게 합니다.
- **장 번호(3/8)**: 끝이 보이면 끝까지 봅니다.
- **한 장에 문단 금지.** 40자로 안 되면 두 장으로.
- **정리 장은 따로 떼어 봐도 이해되게.** 공유가 가장 강한 신호입니다.
- **모든 장에 계정 이름**을 작게 아래 구석에. 캡처는 계정 없이 돌아다닙니다.
- **표지만이라도 대체 텍스트(alt)를 씁니다.**

## 쿠팡 상품 캐러셀

직접 써 본 상품을 비교·정리하는 캐러셀은 쿠팡 파트너스와 잘 맞습니다.
- 표지: 상황 + 결론(예: "자취 3년, 에어프라이어는 이거 하나")
- 본문: 고른 이유·단점까지 솔직하게. 단점이 없는 후기는 광고로 읽힙니다
- 링크는 캡션이 아니라 프로필 링크·스토리 링크 스티커로
- 캡션과 마지막 장에 **대가성 문구**

## 출력

장마다 `번호 · 제목 · 본문` 표, 표지 alt, 캡션(`caption.md` 규칙)을 함께 줍니다. 이미지는 toolhub 썸네일 만들기나 디자인 도구로 사람이 만듭니다.
