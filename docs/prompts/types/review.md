# 글 유형: 리뷰

상품·서비스를 **직접 써 본 경험**을 바탕으로 구매 판단을 돕는 글입니다. 예: 에어프라이어 추천, 무선 이어폰 비교, OTT 요금제 후기.

검색 엔진은 리뷰를 평가할 때 **직접 사용한 흔적**(직접 찍은 사진, 사용 기간, 구체적인 장단점, 비교)을 특히 중요하게 봅니다. 그래서 리뷰 초안은 뼈대와 조사 내용으로 완성된 문장을 쓰고, **경험은 사람이 덧붙이도록** "사람이 할 일"에 꼼꼼히 안내합니다. 본문에 빈자리(`[직접 작성]`)를 두지 않고, 써 보지 않은 경험을 지어내지 않습니다.

## 구성 변형

브리프의 `구성:`에 적힌 변형을 따릅니다. 없으면 키워드에 가장 맞는 것을 고릅니다. 어떤 변형이든 **기본 정보(제품명·주요 사양·가격대)** 는 한 번 표로 정리하고, 가격처럼 자주 바뀌는 정보는 "글 쓴 시점 기준"을 밝히거나 판매처에서 확인하라고 씁니다.

### A. 요약 먼저형
1. 도입: 어떤 상황에서 이 상품을 찾게 되는지.
2. 한눈에 요약: 추천 대상 / 비추천 대상 / 한 줄 평.
3. 기본 정보 표.
4. 실사용 후기: 사용 장면별 소제목 2~4개.
5. 장점과 단점.
6. 마무리: 추천 결론.

### B. 사용 기간 순
1. 구매 전 고민: 어떤 후보를 놓고 왜 망설였는지.
2. 기본 정보 표.
3. 첫인상: 개봉·설치.
4. 일주일 사용.
5. 한 달 이후: 익숙해진 뒤 보이는 장단점.
6. 결론: 지금 다시 산다면.

### C. 장단점 중심형
1. 한 줄 평. 점수는 사람이 매기도록 "사람이 할 일"에 둡니다.
2. 기본 정보 표.
3. 좋았던 점: 소제목 2~4개, 각각 구체적인 장면과 함께.
4. 아쉬운 점: 소제목 1~3개. 카페 글·실제 질문에서 사람들이 자주 말하는 단점을 정리합니다.
5. 추천 대상 / 비추천 대상.

### D. 비교형
1. 도입: 비교하게 된 이유.
2. 후보 비교표: 이 상품과 대안 1~2개 (조사한 정보 기준, 직접 비교하지 않았다면 그 사실을 밝힘).
3. 이 상품을 고른 이유.
4. 실사용 후기.
5. 다른 후보가 더 맞는 사람.

변형과 상관없이, 본문에서 다루지 못한 짧은 질문이 실제 질문(지식iN)·카페 글에 많으면 "자주 묻는 질문"을 2~3개 덧붙여도 됩니다.

## 사람이 채울 자리

- **이미지**: 글 전체 5~8개, 대부분 `추천: 직접 촬영` (개봉, 실제 사용 장면, 디테일, 크기 비교). 제조사·쇼핑몰 이미지는 추천하지 않습니다.
- **덧붙일 경험**(본문 밖, "사람이 할 일"에 **필수**로): 4곳 이상, 어느 소제목 아래에 무엇을 쓸지. 구매 계기, 사용 기간, 구체적인 사용 장면, 기대와 달랐던 점, 단점의 실제 체감, 점수·재구매 의사.

## 주의

- 협찬·제휴 링크를 쓰는 경우 공정위 표시(대가성 문구)가 필요하다고 "사람이 할 일"에 안내합니다.
- 건강·안전과 관련된 효능은 단정하지 않습니다.
