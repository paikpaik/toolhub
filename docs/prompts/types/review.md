# 글 유형: 리뷰

상품·서비스를 **직접 써 본 경험**을 바탕으로 구매 판단을 돕는 글입니다. 예: 에어프라이어 추천, 무선 이어폰 비교, OTT 요금제 후기.

검색 엔진은 리뷰를 평가할 때 **직접 사용한 흔적**(직접 찍은 사진, 사용 기간, 구체적인 장단점, 비교)을 특히 중요하게 봅니다. 그래서 리뷰 초안은 뼈대와 조사 내용을 제공하고, **경험은 사람이 채우도록** 자리를 많이 둡니다. 써 보지 않은 경험을 지어내지 않습니다.

## 글 구조

1. **도입 (2~3문장)**: 어떤 상황에서 이 상품을 찾게 되는지, 이 글에서 무엇을 알 수 있는지. `[직접 작성: 구매(사용) 계기]`
2. **한눈에 요약**: 추천 대상 / 비추천 대상 / 한 줄 평을 표나 목록으로.
3. **기본 정보**: 제품명, 주요 사양, 가격대를 표로. 가격처럼 자주 바뀌는 정보는 `[확인 필요: 현재 가격]`으로 둡니다.
4. **실사용 후기 (소제목 2~4개)**: 사용 장면별로 나눕니다 (예: 첫 설치, 일주일 사용, 세척·관리). 각 소제목에 `[직접 작성]`과 `[이미지: 직접 촬영]`을 둡니다.
5. **장점과 단점**: 카페 글·실제 질문에서 사람들이 자주 말하는 장단점을 참고해 정리하고, 글쓴이의 경험으로 확인할 자리를 둡니다.
6. **비교·대안**: 비슷한 가격대 대안 1~2개와 차이. 조사한 정보 기준으로 쓰고, 직접 비교하지 않았다면 그 사실을 밝힙니다.
7. **자주 묻는 질문 (3개)**: 실제 질문(지식iN)·카페 글에서 고릅니다.
8. **마무리**: 이런 분께 추천한다는 결론. `[직접 작성: 재구매 의사와 이유]`

## 사람이 채울 자리

- **이미지**: 글 전체 5~8개, 대부분 `추천: 직접 촬영` (개봉, 실제 사용 장면, 디테일, 크기 비교). 제조사·쇼핑몰 이미지는 추천하지 않습니다.
- **직접 작성**: 4곳 이상. 사용 기간, 구체적인 사용 장면, 기대와 달랐던 점, 단점의 실제 체감.

## 주의

- 협찬·제휴 링크를 쓰는 경우 공정위 표시(대가성 문구)가 필요하다고 "사람이 할 일"에 안내합니다.
- 건강·안전과 관련된 효능은 단정하지 않습니다.
