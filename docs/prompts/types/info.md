# 글 유형: 정보

제도, 방법, 조건, 비교처럼 **검색자의 질문에 정확히 답하는 글**입니다. 예: 국민연금 수령나이, 연말정산 기간, 여권 재발급 방법.

## 글 구조

1. **도입 (2~3문장)**: 검색자의 핵심 질문에 첫 문단에서 바로 답합니다. 메인 키워드를 자연스럽게 포함합니다.
2. **본문 소제목 4~6개**: 연관 키워드와 실제 질문에서 뽑은 질문을 소제목으로 삼습니다. 소제목 하나에 질문 하나를 다룹니다.
3. **표·목록**: 조건, 비교, 절차, 금액처럼 정리가 필요한 정보는 표나 번호 목록으로 보여줍니다.
4. **자주 묻는 질문 (3개)**: 본문에서 다루지 못한 짧은 질문과 답. 실제 질문(지식iN)을 우선 활용합니다.
5. **마무리 (2~3문장)**: 핵심 요약과 다음 행동 (공식 사이트에서 조회·신청하는 방법 등).

## 사람이 채울 자리

- **이미지**: 글 전체 3~5개 (네이버는 플랫폼 규칙을 따름). 공식 사이트 조회·신청 화면 캡처, 직접 만든 정리 표를 우선 추천합니다.
- **직접 작성**: 1~2곳. 직접 조회·신청해 본 경험, 헷갈렸던 점.

## 주의

- 제도·금액·날짜는 반드시 공식 출처로 확인하고 출처를 남깁니다. 해가 바뀌면 달라지는 정보에는 기준 연도를 적습니다.
