# 글 유형: 정보

제도, 방법, 조건, 비교처럼 **검색자의 질문에 정확히 답하는 글**입니다. 예: 국민연금 수령나이, 연말정산 기간, 여권 재발급 방법.

## 구성 변형

브리프의 `구성:`에 적힌 변형을 따릅니다. 없으면 키워드에 가장 맞는 것을 고릅니다. 어떤 변형이든 **첫 문단 안에 검색자의 핵심 질문에 대한 답**이 있어야 합니다.

### A. 질문 답변형
1. 도입: 핵심 질문에 바로 답합니다.
2. 소제목 4~6개: 연관 키워드·실제 질문에서 뽑은 질문 하나씩.
3. 마무리: 핵심 요약과 다음 행동.

### B. 결론 먼저형
1. 결론 요약: 3~5줄 요약(목록이나 짧은 표).
2. 근거와 세부 내용: 소제목 3~4개로 요약의 각 항목을 풀어 설명.
3. 예외·주의할 점: 헷갈리기 쉬운 경우, 놓치기 쉬운 조건.
4. 마무리: 지금 할 일 한두 가지.

### C. 상황으로 시작형
1. 도입: 독자가 겪을 법한 구체적인 상황 하나로 시작하고, 바로 답으로 이어집니다.
2. 문제 정리: 왜 헷갈리는지, 무엇을 알아야 하는지.
3. 단계별 방법: 번호 목록으로 순서대로.
4. 자주 하는 실수: 2~3개.
5. 마무리.

### D. 비교·표 중심형
1. 도입: 무엇을 비교하는 글인지 한두 문장.
2. 비교표: 선택지(조건·대상·금액·기간 등)를 한눈에.
3. 항목별 설명: 표의 각 선택지를 소제목으로.
4. 상황별 추천: "이런 경우엔 이것".
5. 마무리.

## 사람이 채울 자리

- **이미지**: 글 전체 3~5개 (네이버는 플랫폼 규칙을 따름). 공식 사이트 조회·신청 화면 캡처, 직접 만든 정리 표를 우선 추천합니다.
- **직접 작성**: 1~2곳. 직접 조회·신청해 본 경험, 헷갈렸던 점.

## 주의

- 제도·금액·날짜는 반드시 공식 출처로 확인하고 출처를 남깁니다. 해가 바뀌면 달라지는 정보에는 기준 연도를 적습니다.
