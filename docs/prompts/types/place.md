# 글 유형: 장소

맛집, 카페, 여행지, 시설처럼 **직접 방문한 장소**를 소개하는 글입니다. 예: 성수동 브런치 카페, 제주 아이와 가볼만한곳, ○○ 캠핑장 후기.

리뷰와 마찬가지로 **직접 방문한 경험이 핵심**입니다. 방문하지 않은 분위기나 맛을 지어내지 않고, 사람이 채울 자리를 많이 둡니다.

## 구성 변형

브리프의 `구성:`에 적힌 변형을 따릅니다. 없으면 키워드에 가장 맞는 것을 고릅니다. 어떤 변형이든 **기본 정보 표**(이름, 주소, 영업시간, 휴무일, 주차, 예약 여부)를 한 번 넣습니다. 이름·주소는 브리프의 **장소 정보**를 그대로 쓰고, 영업시간·가격·주차처럼 없는 정보는 `[확인 필요: …]`로 둡니다.

### A. 정보 먼저형
1. 도입: 어떤 사람에게 어떤 상황에 좋은 곳인지. `[직접 작성: 방문 계기와 날짜·시간대]`
2. 기본 정보 표.
3. 찾아가는 길: 대중교통·주차 팁.
4. 분위기·공간.
5. 메뉴·가격(맛집·카페) 또는 시설·코스(여행지·시설).
6. 방문 팁.
7. 마무리: 재방문 의사와 추천 대상.

### B. 방문 동선 순
1. 도착: 첫인상과 외관. `[직접 작성: 방문 날짜·시간대, 대기 여부]`
2. 입장·주문(또는 매표·입장).
3. 메뉴·체험: 먹고 경험한 순서대로.
4. 나가는 길과 주변: 함께 들르기 좋은 곳 1~2곳.
5. 기본 정보 표.
6. 총평.

### C. 추천 포인트형
1. 이런 분께 추천: 포인트 3가지를 목록으로.
2. 포인트별 상세: 각 포인트를 소제목으로, 사진 자리와 함께.
3. 아쉬운 점: `[직접 작성]`
4. 기본 정보 표.
5. 방문 팁.

### D. 상황별 가이드
1. 도입: 이 장소를 찾는 사람들의 대표 상황.
2. 상황별 이용법: 혼자 / 데이트 / 가족·아이 동반 등 상황 2~3개를 소제목으로 (메뉴·자리·시간대 추천).
3. 기본 정보 표.
4. 메뉴·시설 정리.
5. 마무리.

## 사람이 채울 자리

- **이미지**: 글 전체 6~10개, 거의 모두 `추천: 직접 촬영` (외관, 내부, 메뉴·시설, 메뉴판, 주변). 다른 블로그·지도 서비스 사진은 추천하지 않습니다.
- **직접 작성**: 4곳 이상. 방문 날짜·시간대, 대기 시간, 맛·분위기의 구체적인 느낌, 아쉬운 점.

## 주의

- 장소 이름·주소는 브리프의 장소 정보와 반드시 일치시킵니다. 장소 정보가 여러 개면 키워드와 가장 맞는 곳을 고르고, 애매하면 `[확인 필요: 정확한 장소]`로 표시합니다.
- 영업시간·가격·휴무는 자주 바뀌므로 발행 직전에 확인하라고 "사람이 할 일"에 안내합니다.
