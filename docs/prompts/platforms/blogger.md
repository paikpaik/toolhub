# 플랫폼 규칙: Blogger (구글 블로그)

글쓰기 화면 왼쪽 위의 **연필 아이콘 → HTML 보기**로 바꾼 뒤 본문을 붙여넣는 것을 전제로 합니다.
Blogger는 구글 검색 노출이 중심이고, 애드센스와 기본으로 연동됩니다.

## 분량
- 본문 2,000~3,500자 (공백 포함). 구글은 주제를 충분히 다룬 글을 선호하지만 군더더기는 넣지 않습니다.

## 제목
- 30~50자. 메인 키워드를 앞쪽에 둡니다.

## 메타 설명 (검색 설명)
- 글 설정의 **검색 설명** 칸에 넣을 문장입니다. 120~150자, 메인 키워드 포함, 글을 읽으면 무엇을 알 수 있는지 요약합니다.
- 설정에서 "검색 설명" 기능이 꺼져 있으면 블로그 설정 → 메타 태그에서 켜야 한다고 "사람이 할 일"에 안내합니다.

## 퍼머링크
- 출력의 메타 설명 아래에 **맞춤 퍼머링크**를 하나 제안합니다. 영문 소문자와 하이픈으로, 3~6단어 (예: `national-pension-age-by-birth-year`).

## 태그 (라벨)
- 라벨 3~5개. 블로그 안의 분류 역할이므로 너무 세세하게 나누지 않습니다.

## 본문 HTML 형식
- 코드 블록 언어는 `html`.
- 사용 태그: `<h2>`, `<h3>`, `<p>`, `<ul>`/`<ol>`/`<li>`, `<table>`, `<strong>`, `<blockquote>`, `<a>`.
- `<h1>`은 쓰지 않습니다.
- 표는 티스토리와 같은 최소 `style`을 씁니다.
  ```html
  <table style="width:100%; border-collapse:collapse;">
    <tr><th style="border:1px solid #ddd; padding:8px;">구분</th><th style="border:1px solid #ddd; padding:8px;">내용</th></tr>
  </table>
  ```
- 글 앞부분(도입 다음)에 소제목 목차를 넣습니다. 각 `<h2>`에 영문 `id`를 붙이고 목차에서 링크합니다.
  ```html
  <ul>
    <li><a href="#age-table">출생연도별 수령나이</a></li>
  </ul>
  <h2 id="age-table">출생연도별 수령나이</h2>
  ```
- "자주 묻는 질문"을 넣는 경우 `<h2>자주 묻는 질문</h2>` 아래에 질문을 `<h3>`, 답을 `<p>`로 씁니다.
- 사람이 채울 자리는 별도 문단으로 넣습니다.
  ```html
  <p>[이미지: … | alt: … | 추천: …]</p>
  <p>[직접 작성: …]</p>
  ```
