# 플랫폼 규칙: 네이버 블로그

네이버 스마트에디터는 HTML 붙여넣기를 지원하지 않으므로 **일반 텍스트**로 출력합니다. 서식(소제목, 표, 강조)은 에디터에서 사람이 적용합니다.
네이버 블로그에는 애드센스를 붙일 수 없고, 수익은 애드포스트로 얻습니다. 검색 노출은 네이버 검색 중심입니다.

## 분량
- 본문 1,500~2,500자 (공백 포함). 네이버는 모바일 독자가 많아 짧은 문단이 읽기 좋습니다.

## 제목
- 25~35자. 메인 키워드를 앞쪽에 두고, 제목에 키워드를 한 번만 넣습니다.

## 메타 설명
- 네이버 블로그에는 따로 입력하는 칸이 없습니다. 출력의 "메타 설명" 항목은 `해당 없음`으로 적습니다.

## 태그
- 10개 안팎. 메인 키워드, 연관 키워드, 주제 분류어.

## 본문 텍스트 형식
- 코드 블록 언어는 `text`.
- **소제목**은 아래처럼 앞뒤에 빈 줄을 두고 `■`로 시작합니다. 사람이 에디터에서 "소제목" 서식으로 바꿉니다.
  ```
  ■ 출생연도별 국민연금 수령나이
  ```
- **문단**은 1~3문장마다 빈 줄로 끊습니다. 모바일 화면에서 한 문단이 4줄을 넘지 않게 합니다.
- **강조**할 문장 앞에는 `★`를 붙입니다. 사람이 굵게 처리하고 `★`를 지웁니다.
- **표**는 텍스트로 정리하고, 바로 아래에 표 이미지 자리를 둡니다. 사람이 에디터의 표 기능으로 옮기거나 캡처해서 넣습니다.
  ```
  [표: 출생연도 | 수령나이]
  1953~1956년생 | 61세
  1957~1960년생 | 62세

  [이미지: 위 표를 캡처한 이미지 | alt: 출생연도별 국민연금 수령나이 표 | 추천: 표 캡처]
  ```
- **이미지 자리**는 다른 플랫폼보다 많이 둡니다. 글 전체 5~8개, 소제목마다 1개 이상을 기본으로 합니다. 네이버는 이미지가 풍부한 글을 선호합니다.
- 메인 키워드는 본문에 3~5회 자연스럽게 반복합니다. 그 이상 반복하지 않습니다.
- 외부 링크는 꼭 필요한 공식 사이트만 1~2개 넣습니다.
- 사람이 채울 자리 표시(`[이미지: …]`, `[직접 작성: …]`, `[확인 필요: …]`)는 별도 줄에 둡니다.
