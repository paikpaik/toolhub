# 플랫폼 규칙: 네이버 블로그

네이버 스마트에디터는 HTML 붙여넣기를 지원하지 않으므로 **일반 텍스트**로 출력합니다. 서식(소제목, 표, 강조)은 에디터에서 사람이 적용합니다.
네이버 블로그에는 애드센스를 붙일 수 없고, 수익은 애드포스트로 얻습니다. 검색 노출은 네이버 검색 중심입니다.

## 분량
- 본문 **목표 2,000자** (공백 포함, 범위 1,500~2,500자). 1,500자는 최소일 뿐 목표가 아닙니다. 네이버는 모바일 독자가 많아 짧은 문단이 읽기 좋습니다.
- 분량 배분: 도입 150~250자 + 소제목 5~6개 × 각 280~380자 + 마무리 100~200자. 소제목 하나가 200자 아래로 끝나면 그 소제목에 답·예시·상황별 판단을 더합니다.

## 제목
- 25~35자. 메인 키워드를 앞쪽에 두고, 제목에 키워드를 한 번만 넣습니다.

## 홈판(메인) 노출

지금 뜨는 이슈(브리프의 `최근 7일`이 급상승·상승, 실시간·홈판 키워드)는 검색뿐 아니라 네이버 메인 홈판(추천 피드) 노출을 함께 노립니다. 네이버가 선정 기준을 공개하지 않아 아래는 일반적으로 알려진 경향입니다.

- **속도**: 이슈가 뜬 당일, 가능하면 몇 시간 안에 발행합니다. 늦으면 같은 주제 글이 쌓여 밀립니다.
- **제목**: 궁금증을 주되 내용과 일치해야 합니다 (지침의 과장·낚시 금지는 그대로). 숫자·대상·변화를 구체적으로 씁니다 (예: "11월 6일부터 달라지는 ○○ 3가지, 나도 해당될까"). "충격", "무조건", "결국" 같은 자극어는 쓰지 않습니다.
- **대표 썸네일**: 홈판 카드에 첫 이미지가 크게 보입니다. 썸네일 만들기로 제목의 핵심(대상·숫자)을 크게 넣습니다.
- **도입 3줄 요약**: 첫 문단에 무슨 일인지·나와 무슨 상관인지·이 글에서 알 수 있는 것을 3줄 안에 씁니다. 날짜 기준을 밝힙니다 ("11월 6일 기준").
- **끝까지 읽히게**: 소제목마다 한 가지 질문에 답하고, 표·정리 문단으로 훑어보기 쉽게 합니다. 마지막에 다음 일정·확인할 곳처럼 이어서 필요한 정보를 둡니다.
- 확인되지 않은 속보·추측은 쓰지 않습니다. 빠르게 쓰더라도 사실 확인 원칙은 같습니다.

## 메타 설명
- 네이버 블로그에는 따로 입력하는 칸이 없습니다. 출력의 "메타 설명" 항목은 `해당 없음`으로 적습니다.

## 태그
- 10개 안팎. 메인 키워드, 연관 키워드, 주제 분류어.

## 본문 텍스트 형식
- 코드 블록 언어는 `text`.
- **소제목**은 아래처럼 앞뒤에 빈 줄을 두고 `■`로 시작합니다. 사람이 에디터에서 "소제목" 서식으로 바꿉니다.
  ```
  ■ 출생연도별 국민연금 수령나이
  ```
- **문단**은 1~3문장마다 빈 줄로 끊습니다. 모바일 화면에서 한 문단이 4줄을 넘지 않게 합니다.
- **강조**할 문장 앞에는 `★`를 붙입니다. 사람이 굵게 처리하고 `★`를 지웁니다.
- **표**는 텍스트로 정리합니다. 초안 화면의 "서식 포함 복사"가 표로 바꿔 주므로 표 이미지 자리는 두지 않습니다.
  ```
  [표: 출생연도 | 수령나이]
  1953~1956년생 | 61세
  1957~1960년생 | 62세
  ```
- **이미지 자리**는 `writing.md` 규칙대로 대표 썸네일 1개(본문 첫 줄, `추천: 썸네일 만들기`로 직접 제작) + 본문 이미지 5개이고, 본문 이미지는 모두 `추천: AI 생성` 장면입니다.
- 메인 키워드는 본문에 3~5회 자연스럽게 반복합니다. 그 이상 반복하지 않습니다.
- 외부 링크는 꼭 필요한 공식 사이트만 1~2개 넣습니다.
- 이미지 자리 표시(`[이미지: …]`)는 별도 줄에 둡니다.
