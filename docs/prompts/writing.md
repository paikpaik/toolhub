# 초안 작성 규칙 (`[글쓰기 브리프]`)

## 입력 형식

toolhub의 키워드 분석에서 가져온 브리프입니다.

```
[글쓰기 브리프]
플랫폼: 티스토리            (티스토리 | Blogger | 네이버)
키워드: 국민연금 수령나이
월간 검색량: 21,000 (PC 3,000 / 모바일 18,000) · 경쟁도: 낮음
연관 키워드 (검색량 순):
| 키워드 | 월간 검색량 | 경쟁도 |
|---|---|---|
| 국민연금 수령나이 조회 | 9,800 | 낮음 |
| ... |
참고: (선택. 관련 뉴스, 글 각도, 직접 경험 메모 등)
```

## 작성 순서

1. **검색 의도 파악**: 키워드와 연관 키워드를 보고 검색자가 알고 싶은 질문 3~5개를 정합니다. 연관 키워드는 검색자의 실제 질문 목록입니다.
2. **사실 확인**: 웹 검색으로 최신 정보를 확인합니다. 지침의 "사실 확인" 원칙을 따릅니다.
3. **구성 → 작성**: 아래 구조로 씁니다.
4. **플랫폼 형식 적용**: 브리프의 `플랫폼`에 맞는 `platforms/*.md` 규칙으로 본문을 출력합니다.

## 글 구조

1. **도입 (2~3문장)**: 검색자의 핵심 질문에 첫 문단에서 바로 답합니다. 메인 키워드를 자연스럽게 포함합니다.
2. **본문 소제목 4~6개**: 연관 키워드에서 뽑은 질문을 소제목으로 삼습니다. 소제목 하나에 질문 하나를 다룹니다.
3. **표·목록**: 조건, 비교, 절차, 금액처럼 정리가 필요한 정보는 표나 번호 목록으로 보여줍니다.
4. **자주 묻는 질문 (3개)**: 본문에서 다루지 못한 짧은 질문과 답.
5. **마무리 (2~3문장)**: 핵심 요약과 다음 행동(공식 사이트에서 조회하는 방법 등).

분량은 플랫폼 규칙을 따릅니다.

## 키워드 사용

- 메인 키워드: 제목 앞쪽, 도입 첫 문단, 소제목 1~2곳에 자연스럽게 넣습니다.
- 연관 키워드: 검색량이 많은 순으로 소제목과 본문에 자연스럽게 녹입니다. 억지로 다 넣지 않습니다.
- 같은 키워드를 문장마다 반복하는 키워드 남용은 하지 않습니다.

## 사람이 채울 자리

초안을 사람이 다듬을 수 있도록 아래 표시를 본문에 넣습니다. 표시는 대괄호로 시작해 눈에 잘 띄게 합니다.

- **이미지 자리**: 이미지가 있으면 이해가 쉬워지는 위치에 넣습니다. 소제목마다 0~1개, 글 전체 3~5개가 기본입니다 (네이버는 플랫폼 규칙을 따름).
  ```
  [이미지: 무엇을 보여주는 이미지인지 | alt: 대체 텍스트 | 추천: 직접 캡처 / 직접 촬영 / 무료 사진(검색어: 영문 검색어)]
  ```
  - 예: `[이미지: 국민연금공단 홈페이지 예상 연금액 조회 화면 | alt: 국민연금 예상연금 조회 화면 | 추천: 직접 캡처]`
  - 공식 사이트 화면, 직접 만든 표처럼 **직접 만들 수 있는 이미지**를 우선 추천합니다.
- **직접 경험 자리**: 글쓴이의 경험이 들어가면 신뢰가 높아지는 위치에 1~2곳 넣습니다.
  ```
  [직접 작성: 무엇을 쓰면 좋은지 안내]
  ```
  - 예: `[직접 작성: 실제로 예상 연금액을 조회해 본 결과와 느낀 점]`
- **확인 필요**: 웹 검색으로 확인하지 못한 정보는 `[확인 필요: 내용]`으로 표시합니다.

## 출력 형식

아래 순서로 출력합니다. 각 항목은 제목(`##`)으로 구분합니다.

1. **제목 후보 3개**: 메인 키워드를 앞쪽에 넣고, 플랫폼 규칙의 글자 수를 지킵니다. 추천 1개를 표시합니다.
2. **메타 설명**: 플랫폼 규칙에 따릅니다.
3. **태그**: 플랫폼 규칙의 개수를 지킵니다. 쉼표로 구분합니다.
4. **본문**: 플랫폼 형식으로, 복사하기 쉽게 **코드 블록 하나**에 담습니다.
5. **이미지 목록**: 본문의 `[이미지: …]` 표시를 순서대로 다시 정리한 표 (번호, 위치(소제목), 내용, alt, 추천 방법).
6. **사람이 할 일**: `[직접 작성]`, `[확인 필요]` 목록과 발행 전 확인 사항.
7. **참고한 출처**: 사실 확인에 사용한 공식 출처 링크.
8. **스레드 홍보글**: `threads.md` 규칙에 따릅니다.
