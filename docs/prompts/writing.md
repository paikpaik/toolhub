# 초안 작성 규칙 (`[글쓰기 브리프]`)

모든 글 유형에 공통인 규칙입니다. 글 구조와 사람이 채울 자리의 기준은 브리프의 `유형`에 맞는 `types/*.md`를 함께 따릅니다.

## 입력 형식

toolhub가 만든 브리프입니다. 키 설정에 따라 일부 항목이 빠질 수 있습니다.

```
[글쓰기 브리프]
플랫폼: 티스토리            (티스토리 | Blogger | 네이버)
유형: 정보                  (정보 | 리뷰 | 장소)
키워드: 국민연금 수령나이
월간 검색량: 58,040 (PC 8,440 / 모바일 49,600) · 경쟁도: 중간
검색 추이: 꾸준함 — 1년 내내 검색량이 고르게 유지됩니다.
블로그 문서 수: 152,300 (검색량의 2.6배 · 포화도 보통)
연관 키워드 (관련 높은 순):
| 키워드 | 월간 검색량 | 경쟁도 |
|---|---|---|
| 국민연금 | 287,000 | 낮음 |
| ... |
실제 질문 (지식iN):
- 1968년생 국민연금 언제부터 받나요?
- ...
상위 블로그 글 (겹치지 않는 각도를 잡기 위한 참고):
- 국민연금 수령나이 총정리 (2026-09-12)
- ...
카페 글 (실제 후기·고민):        (리뷰·장소 유형에만)
- ...
장소 정보 (네이버 지역 검색):    (장소 유형에만)
| 이름 | 분류 | 도로명 주소 | 링크 |
참고: (선택. 글 각도, 직접 경험 메모 등)
```

| 항목 | 쓰는 방법 |
|---|---|
| 연관 키워드 | 메인 키워드의 단어를 포함한 것이 앞에 오고, 뒤로 갈수록 넓은 관심사입니다. 주제와 먼 키워드는 쓰지 않아도 됩니다 |
| 검색 추이 | `시즌`이면 시기를 제목·도입에 반영하고(예: "2027년 연말정산"), `급등 이력`·`하락세`면 지나간 이슈보다 오래 유효한 정보 위주로 씁니다 |
| 블로그 문서 수·포화도 | 포화도가 `높음`이면 이미 비슷한 글이 많다는 뜻입니다. 더 좁은 롱테일 각도나 상위 글에 없는 정보로 차별화합니다 |
| 실제 질문 | 검색자가 실제로 묻는 질문입니다. 소제목과 "자주 묻는 질문"을 우선 여기서 고릅니다. 질문 문장을 그대로 베끼지 말고 일반화합니다 |
| 상위 블로그 글 | 이미 상위에 있는 글의 제목입니다. **같은 구성·제목을 피하고**, 빠진 정보나 다른 관점으로 씁니다. 글을 열어 내용을 베끼지 않습니다 |
| 카페 글 | 실제 사용자의 후기·고민입니다. 장단점과 "이런 분께 추천/비추천"을 정리하는 데 참고합니다 |
| 장소 정보 | 장소의 공식 이름·분류·주소입니다. 이 정보와 다르게 쓰지 않고, 영업시간·가격처럼 없는 정보는 `[확인 필요]`로 둡니다 |

- `월간 검색량: 조회하지 않음`이거나 항목이 빠져 있으면 있는 정보만으로 작성하고, 부족한 검색 의도는 웹 검색으로 보완합니다.

## 작성 순서

1. **검색 의도 파악**: 키워드, 연관 키워드, 실제 질문을 보고 검색자가 알고 싶은 질문 3~5개를 정합니다.
2. **차별화 각도**: 상위 블로그 글 제목과 포화도를 보고, 같은 내용을 반복하지 않을 각도를 한 줄로 정합니다.
3. **사실 확인**: 웹 검색으로 최신 정보를 확인합니다. 지침의 "사실 확인" 원칙을 따릅니다.
4. **구성 → 작성**: `유형`에 맞는 `types/*.md`의 글 구조로 씁니다.
5. **플랫폼 형식 적용**: `플랫폼`에 맞는 `platforms/*.md` 규칙으로 본문을 출력합니다.

## 키워드 사용

- 메인 키워드: 제목 앞쪽, 도입 첫 문단, 소제목 1~2곳에 자연스럽게 넣습니다.
- 연관 키워드: 관련 높은 순으로 소제목과 본문에 자연스럽게 녹입니다. 억지로 다 넣지 않습니다.
- 같은 키워드를 문장마다 반복하는 키워드 남용은 하지 않습니다.

## 사람이 채울 자리

초안을 사람이 다듬을 수 있도록 아래 표시를 본문에 넣습니다. 표시는 대괄호로 시작해 눈에 잘 띄게 합니다. 개수와 위치의 기준은 `types/*.md`를 따릅니다.

- **이미지 자리**
  ```
  [이미지: 무엇을 보여주는 이미지인지 | alt: 대체 텍스트 | 추천: 직접 캡처 / 직접 촬영 / 무료 사진(검색어: 영문 검색어)]
  ```
  - 예: `[이미지: 국민연금공단 홈페이지 예상 연금액 조회 화면 | alt: 국민연금 예상연금 조회 화면 | 추천: 직접 캡처]`
  - 공식 사이트 화면, 직접 만든 표, 직접 찍은 사진처럼 **직접 만들 수 있는 이미지**를 우선 추천합니다.
- **직접 경험 자리**
  ```
  [직접 작성: 무엇을 쓰면 좋은지 안내]
  ```
  - 예: `[직접 작성: 실제로 예상 연금액을 조회해 본 결과와 느낀 점]`
- **확인 필요**: 웹 검색으로 확인하지 못한 정보는 `[확인 필요: 내용]`으로 표시합니다.

## 출력 형식

아래 순서로 출력합니다. 각 항목은 제목(`##`)으로 구분합니다.

1. **제목 후보 3개**: 메인 키워드를 앞쪽에 넣고, 플랫폼 규칙의 글자 수를 지킵니다. 추천 1개를 표시합니다.
2. **메타 설명**: 플랫폼 규칙에 따릅니다.
3. **태그**: 플랫폼 규칙의 개수를 지킵니다. 쉼표로 구분합니다.
4. **본문**: 플랫폼 형식으로, 복사하기 쉽게 **코드 블록 하나**에 담습니다.
5. **이미지 목록**: 본문의 `[이미지: …]` 표시를 순서대로 다시 정리한 표 (번호, 위치(소제목), 내용, alt, 추천 방법).
6. **사람이 할 일**: `[직접 작성]`, `[확인 필요]` 목록과 발행 전 확인 사항.
7. **참고한 출처**: 사실 확인에 사용한 공식 출처 링크.
8. **스레드 홍보글**: `threads.md` 규칙에 따릅니다.
