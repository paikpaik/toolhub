# toolhub

**할 일 관리와 블로그 운영을 한곳에서.** 내 맥에서 돌아가는 개인 업무 도구입니다.

오늘 할 일을 정리하고, 지금 뜨는 키워드에서 글감을 찾고, Claude와 함께 초안을 쓰고, 썸네일까지 만들어 발행 준비를 끝낼 수 있습니다. Claude 데스크톱 앱과 연결하면 이 모든 걸 **대화로** 시킬 수도 있어요.

- 💸 **무료**: 쓰는 서비스(네이버 API 등)가 모두 무료이고, 비용이 드는 AI API도 쓰지 않습니다.
- 🔒 **내 PC에만**: 할 일·키워드 기록·초안은 이 맥의 `data/`, `drafts/` 폴더에만 저장됩니다.

## 이런 걸 할 수 있어요

### ✅ 할 일을 말하듯이 적고, 한눈에 관리하기

```
내일 오후 3시 국민연금 글 발행 #블로그 @블로그 운영 !높음 매주
```

이렇게 한 줄만 쓰면 **날짜·시간·태그·프로젝트·우선순위·반복**이 알아서 정리됩니다. 오늘 할 일, 다음 7일, 칸반 보드, 월간 캘린더로 보고, 끌어다 놓아서 상태나 날짜를 바꿀 수 있어요. 반복 할 일은 끝내면 다음 회차가 저절로 생깁니다.

**덩어리 기록**으로는 하루에 3~4시간짜리 집중 작업을 덩어리로(기본 2개, 더 늘릴 수 있어요) 체크하고, 공방·집·SNS 같은 그룹별 주간 목표를 요일로 끌어다 놓아 계획해요.

### 🧭 내 주제에서 "오래 읽히는 글감" 찾기

"캠핑", "연말정산"처럼 **내가 쓰는 주제**를 넣으면, 네이버 연관 키워드 수백 개 중에서 블로그로 쓰기 좋은 것만 골라 줍니다.

- **주제가 들어가고 매달 적당히 검색되는**(월 300~5만 회) 키워드만 — 너무 넓은 주제어나 아무도 안 찾는 말은 빼고
- **방법·신청·조건·비용·추천**처럼 정보를 찾는 키워드를 먼저 — 글 한 편으로 답하기 좋고 오래 검색돼요
- 그중 **글이 아직 적고(포화도 기회) 검색이 줄지 않는** 키워드에 `추천`을 붙이고, 1~3달 뒤가 시즌이면 `곧 시즌`이라고 알려 줘요

실시간 이슈는 며칠 지나면 검색이 끊기지만, 이렇게 찾은 키워드는 **매달 꾸준히 유입**이 들어와서 광고 수익으로 이어지기 좋습니다.

### 🔥 지금 뜨는 키워드에서 "쓸 만한 글감" 찾기

Google Trends·네이트·signal.bz의 실시간 키워드를 모아 날짜별로 쌓아 두고, 키워드마다 이런 걸 보여줍니다.

- **네이버 월간 검색량과 경쟁도** — 많이 찾는데 경쟁이 약한 키워드는?
- **24개월 검색 추이** — 매년 돌아오는 시즌 키워드인지, 반짝 이슈인지
- **포화도** — 검색량에 비해 이미 글이 너무 많지는 않은지
- **사람들이 실제로 묻는 질문**(지식iN), **이미 상위에 있는 블로그 글**, 최신 뉴스, 카페 후기
- **며칠째 계속 뜨는 키워드**인지 (반짝 이슈가 아니라 관심이 이어지는 주제)

다른 곳에서 본 키워드도 됩니다. 네이버 **크리에이터 어드바이저**의 트렌드 화면을 캡처해 Claude 데스크톱 앱에 붙여넣고 "이 키워드들 분석해서 쓸 만한 거 골라줘"라고 하면, 화면 속 키워드를 **한 번에** 조회해 글이 적은 키워드부터 표로 보여줍니다.

### ✍️ 키워드 하나로 블로그 초안 받기

고른 키워드로 Claude에게 초안을 받습니다. 검색량·연관 키워드·실제 질문·상위 글을 담은 **브리프**가 자동으로 만들어져서, 검색자가 궁금해하는 걸 짚으면서 기존 글과 겹치지 않는 초안이 나옵니다.

- **티스토리·Blogger·네이버** 형식을 골라서 받고
- **정보 글·리뷰·장소(맛집·여행)** 유형마다 맞는 구조로
- 글마다 **구성이 달라지고 AI 특유의 상투구를 피해서**, 찍어낸 듯한 글이 되지 않게
- 내 경험을 넣을 자리, 사진을 넣을 자리, 사실 확인이 필요한 곳을 **표시해 줍니다**

### 🚀 발행 준비를 한 화면에서

초안을 열면 블로그에 올렸을 때 모습으로 **미리보기**하고, 제목·태그·본문·스레드 홍보글을 **버튼 하나로 복사**하고, 남은 할 일(사진·경험·확인)을 **체크리스트**로 챙깁니다. **썸네일**도 제목만 넣으면 PNG로 만들어 줍니다.

붙여넣은 뒤 네이버 에디터에서 다듬을 때는 **크롬 확장 프로그램**이 도와줘요.

- 글쓰기 화면 오른쪽 아래의 **toolhub 서식** 버튼(또는 단축키 ⌥⇧1·2·3)으로 `소제목` `강조` `형광펜`을 적용해요. 크기·굵게·색을 하나씩 고르지 않고 **한 번에** 바뀝니다.
- 초안을 **서식 포함 복사**로 붙여넣은 뒤 `소제목 정리`를 누르면, 소제목 줄이 모두 네이버의 진짜 **소제목** 문단 서식으로 바뀌어요.
- 옆 패널을 열어 두면 Gemini·ChatGPT에서 만든 이미지가 **저절로 패널에 모이고**, 클릭하면 복사돼서 에디터에 바로 **⌘V**로 붙여넣어요. 캡처하고 저장하고 다시 올리는 과정이 없어집니다.
- 크리에이터 어드바이저 트렌드 화면에서 우클릭 → **toolhub: 트렌드 키워드 복사**를 누르면 슬라이드로 넘겨야 보이는 카드까지 키워드를 한 번에 복사해요. Claude 앱에 붙여넣으면 오늘 쓸 글을 골라 줍니다.

### 🔗 글감과 일정을 바로 연결

키워드나 초안 옆의 **`+ 할 일`** 을 누르면 문장이 미리 채워진 입력창이 열리고, Enter 한 번이면 일정에 들어갑니다.

- "국민연금 수령나이 글 쓰기 내일" — 키워드 분석 링크가 붙은 할 일
- "국민연금 수령나이 글 발행" — 초안의 남은 자리(사진·경험·확인)가 **하위 할 일로** 들어간 할 일
- "연말정산 시즌 글 준비" — **시즌 5주 전**으로 날짜가 잡힌 알림

### 🎬 블로그 글을 인스타 릴스·카드뉴스로

블로그 글 하나로 인스타그램 게시물 여러 개를 만듭니다. 쓰는 건 Claude가, 점검은 toolhub가, 올리는 건 내가 합니다.

- **릴스 대본** — 훅 공식 26가지 중 골라 훅 후보를 쓰고, 대본을 넣으면 **초 단위 구성표**와 함께 3초 넘는 훅·4초 넘는 장면·숫자 없는 지루한 구간·되감기 문장을 짚어 줘요
- **캡션 점검** — 피드에서 "더 보기" 전에 보이는 부분, 해시태그 5개 제한, 눌리지 않는 링크, 요청 하나, 쿠팡 대가성 문구까지
- **카드뉴스·스토리·댓글** — Claude가 규칙대로 써 줘요 (블로그로 보내는 링크 스티커 스토리, 남의 글에 다는 댓글, 내 글의 댓글 답글)

자동으로 올리거나 댓글·DM을 다는 기능은 **일부러 없습니다**. 인스타그램 약관 위반이고 계정이 제한되기 때문이에요.

## 시작하기

### 1. 설치하고 실행하기

[Node.js](https://nodejs.org) 24 이상이 필요합니다.

```bash
npm install
npm run web
```

브라우저에서 http://localhost:3000 을 열면 첫 화면(일정 관리 › 오늘)이 나옵니다. 여기까지만 해도 **일정 관리와 실시간 키워드**는 바로 쓸 수 있어요.

### 2. 네이버 키 넣기 (선택, 무료)

키를 넣을수록 글감 판단에 쓸 정보가 늘어납니다. 없어도 해당 정보만 빠지고 나머지는 그대로 동작해요.

```bash
cp apps/web/.env.example apps/web/.env.local   # 이 파일에 키를 적습니다 (git에 올라가지 않아요)
```

**① 네이버 검색광고 API** → 월간 검색량·경쟁도·연관 키워드

1. [searchad.naver.com](https://searchad.naver.com)에 가입합니다 (네이버 아이디로 가능, 개인도 사업자등록 없이 가능, 광고비 없이 무료).
2. 광고 시스템 → **도구 → API 사용 관리**에서 키 세 개를 발급받아 적습니다.

```ini
NAVER_SEARCHAD_API_KEY=액세스 라이선스
NAVER_SEARCHAD_SECRET_KEY=비밀키
NAVER_SEARCHAD_CUSTOMER_ID=CUSTOMER_ID
```

**② NAVER API HUB** → 검색 추이·포화도·실제 질문·상위 블로그 글·뉴스·카페 글·장소 정보·쇼핑 트렌드

1. [네이버 클라우드 플랫폼](https://www.ncloud.com)에 가입하고 콘솔에 로그인합니다.
2. **Menu → All Services → Application Services → NAVER API HUB → Application 등록**
3. API는 **검색어 트렌드, 쇼핑 인사이트, 블로그·지식iN·뉴스·카페글·지역 검색**을 고릅니다.
4. **API 관리 → 인증 정보**의 Client ID·Secret을 적습니다.

```ini
NAVER_API_HUB_CLIENT_ID=Client ID
NAVER_API_HUB_CLIENT_SECRET=Client Secret
```

키를 바꾼 뒤에는 웹 서버를 다시 켜 주세요.

### 3. 내 블로그 정보 적기

[docs/prompts/project-instructions.md](docs/prompts/project-instructions.md)의 **"내 블로그 정보"** `[ ]` 부분(주제·독자·말투·관점·플랫폼)을 채워 두세요. 초안의 말투와 관점이 여기서 정해집니다.

인스타그램도 쓴다면 [docs/prompts/instagram/account.md](docs/prompts/instagram/account.md)의 **"내 인스타그램 계정"**(주제·보는 사람·말투·얼굴 노출 등)을 채워 두세요. 릴스 대본은 내가 소리 내 말해야 해서 말투가 특히 중요합니다.

### 4. Claude 데스크톱 앱 연결하기 (선택, 추천)

대화로 할 일을 관리하고 글을 쓰려면 데스크톱 앱에 toolhub를 연결합니다.

1. 터미널에서 `which node`(예: `/usr/local/bin/node`)와, 이 폴더에서 `pwd`(예: `/Users/me/source/toolhub`)를 확인합니다.
2. `~/Library/Application Support/Claude/claude_desktop_config.json`의 `mcpServers`에 추가합니다 (경로는 1번 값으로, 반드시 절대 경로).

   ```json
   {
     "mcpServers": {
       "toolhub": {
         "command": "/usr/local/bin/node",
         "args": [
           "--env-file-if-exists=/Users/me/source/toolhub/apps/web/.env.local",
           "/Users/me/source/toolhub/packages/mcp/src/server.ts"
         ]
       }
     }
   }
   ```

3. 데스크톱 앱을 **완전히 종료(⌘Q)했다가 다시 실행**하면 도구 메뉴에 `toolhub`가 보입니다.

> Claude Code에서는 이 폴더를 열기만 하면 자동으로 연결됩니다 (`.mcp.json`).

### 5. 크롬 확장 프로그램 설치하기 (선택, 네이버 블로그용)

웹 스토어에 올리지 않고 이 폴더에서 바로 설치해 무료로 씁니다.

1. 크롬 주소창에 `chrome://extensions` 를 열고 오른쪽 위 **개발자 모드**를 켭니다.
2. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 안의 `extension` 폴더를 고릅니다.
3. 퍼즐 아이콘에서 **toolhub 글쓰기 도우미**를 고정해 두면 편해요. 이미 열어 둔 네이버 글쓰기 탭은 새로고침하세요.

**크리에이터 어드바이저 트렌드 키워드 복사**
- [크리에이터 어드바이저](https://creator-advisor.naver.com/) › 트렌드 › **검색 유입 트렌드** 화면의 빈 곳에서 우클릭 → **toolhub: 트렌드 키워드 복사**를 누르세요. 카드(맛집, 40-44세 남자 등)마다 키워드와 변동(`new`, `▲3`, `▼2`)이 복사돼요. 슬라이드로 넘겨야 보이는 카드도 함께 읽어요.
- 이어서 **메인 유입 트렌드** 탭에서 한 번 더 누르면 두 탭이 **함께** 복사돼요 (같은 날짜끼리 모이고, 브라우저를 닫으면 비워져요). 화면 아래에 몇 개를 읽었는지 알려 줘요.
- 복사한 글을 Claude 앱에 그대로 붙여넣으면 맨 위 요청 문장("오늘 쓸 글 5개를 골라줘…")대로 골라 줘요. 경쟁이 센 키워드는 연관어로 돌려요.

## 화면 안내

왼쪽 사이드바는 **일정 관리 · 블로그 자동화 · 인스타 자동화** 세 묶음입니다. 지금 보고 있는 화면의 묶음만 펼쳐지고, 다른 묶음은 이름을 눌러 잠깐 열어 볼 수 있어요. 좁은 화면에서는 왼쪽 위 ☰ 버튼을 누르세요.

### 일정 관리

**빠른 추가** — 맨 위 입력창에 한 줄로 적습니다. 입력하는 동안 어떻게 알아들었는지 칩으로 미리 보여줘요. 어느 화면에서든 **`C`** 키를 누르면 바로 입력할 수 있습니다.

| 이렇게 쓰면 | 예 |
|---|---|
| 날짜 | `오늘` `내일` `모레` `월요일` `이번 주 금요일` `다음 주 월요일` `주말` `11월 3일` `11/3` `3일 뒤` |
| 시간 | `오전 9시` `오후 3시 30분` `3시반` `15:30` (시간만 쓰면 오늘) |
| 우선순위 | `!긴급` `!높음` `!보통` `!낮음` |
| 태그 | `#블로그` (여러 개 가능) |
| 프로젝트 | `@블로그 운영` — 있는 프로젝트는 띄어쓰기가 있어도 알아듣고, 없는 이름이면 새로 만들어요 (새 이름은 띄어쓰기 없이) |
| 반복 | `매일` `매주` `매월` `매년` |

보고 있는 화면에 맞춰 알아서 채워 주기도 해요. **오늘** 화면에서 날짜 없이 쓰면 오늘, **프로젝트** 화면에서는 그 프로젝트, **캘린더**에서 날짜를 누른 뒤에는 그 날짜로 들어갑니다.

**보기**

| 메뉴 | 보이는 것 |
|---|---|
| 오늘 | 오늘 할 일 + 지난 일정 (숫자가 빨간색이면 밀린 일이 있다는 뜻) |
| 다음 7일 · 전체 | 지난 일정 / 오늘 / 내일 / 7일 안 / 나중 / 날짜 없음으로 묶어서 |
| 날짜 없음 | 언젠가 할 일 모음 |
| 보드 | 할 일 · 진행 중 · 완료 · 취소 칸. **카드를 끌어서** 상태를 바꿔요 |
| 캘린더 | 월간 달력. **날짜를 누르면** 그날로 추가, **할 일을 끌면** 날짜가 바뀌어요 |
| 완료됨 | 끝낸 일 |
| 프로젝트 · 태그 | 그것만 모아 보기 (프로젝트는 이름 바꾸기·삭제 가능, 지워도 할 일은 남아요) |

**할 일 다루기**

- 왼쪽 **동그라미**를 누르면 완료. 테두리 색은 우선순위(빨강 긴급 · 주황 높음 · 노랑 보통 · 보라 낮음), 반쯤 찬 동그라미는 진행 중이에요.
- 할 일을 누르면 오른쪽에 **상세 패널**이 열려요. 상태·마감일·반복·프로젝트·태그·하위 할 일·메모·링크를 고치면 바로 저장되고, `Esc`로 닫습니다.
- **반복 할 일**을 끝내면 완료 기록은 남고 다음 회차가 새로 생겨요.
- Claude 데스크톱 앱에서 바꾼 내용도 화면에 자동으로 반영돼요.

### 일정 관리 › 덩어리 기록

하루를 "덩어리"(3~4시간, 한 가지 일에 집중한 것) 단위로 기록하고, 그룹별 주간 목표와 이어 주는 화면이에요. 위쪽 탭으로 **오늘 · 주간 보드**를 오갑니다.

| 화면 | 하는 일 |
|---|---|
| 오늘 | 맨 위에 이 날에 **배정된 목표**, 그 아래 덩어리 칸(기본 2칸, **[+ 덩어리 추가]**로 6칸까지, 늘린 칸은 ×로 지우기)에 한 일을 한 줄 적고 그룹(공방·집·SNS)을 고른 뒤 다 하면 동그라미로 체크. 달력 칸은 덩어리 수만큼 세로로 나뉘어 한 덩어리가 그룹 색으로 칠해져요. 맨 아래에는 이달에 한 일(왼쪽)과 월간 달력(날짜를 누르면 지난 기록)이 나란히 보여요 |
| 주간 보드 | `릴스 3개 올리기 #공방 @수`처럼 목표를 추가하고, 그룹 칸에서 **요일 칸으로 끌어다 놓아요**(폰에서는 카드를 눌러 요일 선택). 다른 그룹 칸에 놓으면 그룹만 바뀌고 요일은 그대로예요. 카드를 누르면 **이름 고치기**·요일 고르기·[다음 주로]·삭제가 나와요. 덩어리에서 생긴 카드는 그날 한 일이라 요일이 고정이고, 이름·그룹·완료를 고치면 그날 덩어리에도 같이 반영돼요. 그룹 이름은 칸 머리에서 바로 바꾸고, 이름 옆 동그라미를 누르면 색 바꾸기·**그룹 삭제**가 나와요 (지운 그룹의 목표는 남은 첫 그룹으로 옮겨져요) |

- 덩어리에 메모와 그룹을 적으면 주간 보드의 그 요일에 카드가 저절로 생겨요.
- "배정된 목표"의 **[덩어리에 적기]**를 누르면 목표가 메모로 들어가고, 그 덩어리를 체크하면 목표도 완료돼요.
- 날짜 옆 **하루 끝**에서 하루가 끝나는 시각을 정할 수 있어요(기본 자정, 새벽 8시까지). 예를 들어 새벽 5시로 두면 새벽 3시에 체크해도 아직 "오늘"(전날) 기록으로 들어가요.
- 한 주는 월요일부터예요. 기록은 `data/chunks.json`에 저장돼요.

### 블로그 › 실시간

Google Trends · 네이트 · signal.bz의 **지금 순위**를 한 화면에서 봅니다. `NEW`는 새로 진입, `▲▼`는 순위 변동, 숫자는 구글 검색량(대략)이에요.

> 이 화면을 **열 때마다 처음 보는 키워드가 그날 기록에 쌓입니다.** 하루에 자주 들여다볼수록 그날 뜬 키워드를 빠짐없이 모을 수 있어요.

### 블로그 › 키워드 찾기

주제를 쉼표로 최대 3개 넣고 **찾기**를 누르면(1~3초), 쓸 만한 키워드가 표로 나옵니다.

- 맨 위는 **`추천`** 키워드예요. 검색량에 비해 글이 적고(포화도 기회), 검색이 줄고 있지 않거나 최근 7일 오르는 중인 키워드예요. 반짝 이슈였던 키워드도 빼지 않아요.
- **`곧 시즌`** 은 1~3달 뒤에 검색이 몰리는 키워드예요. 글이 검색에 노출되기까지 몇 주 걸리니 지금 써 두면 시즌에 맞춰집니다.
- 키워드를 누르면 **키워드 분석**으로 넘어가 상위 글·실제 질문을 보고 브리프를 복사할 수 있어요.
- 찾아본 주제는 검색창 아래 **최근**에 남아서 다음엔 한 번 누르면 돼요.
- `추천`이 없으면 주제가 너무 넓은 거예요. "캠핑" 대신 "차박", "캠핑요리"처럼 좁혀 보세요.

> 네이버 검색광고 키가 필요하고, 추천·포화도·시즌은 NAVER API HUB 키까지 있어야 나옵니다.

### 블로그 › 키워드 기록

그날(또는 최근 7일·30일) 뜬 키워드를 표로 봅니다.

- **검색량 순**으로 정렬하면 많이 찾는 키워드가 위로 와요. **경쟁도**가 낮을수록 글감으로 좋습니다.
- 7일·30일 보기에서는 **등장 일수**를 보여줘요. `지속`(3일 이상) 키워드는 반짝 이슈가 아니라 관심이 이어지는 주제라 눈여겨볼 만해요.
- 이미 초안을 쓴 키워드에는 **✓**가 붙어서 같은 주제로 두 번 쓰지 않게 해 줍니다.
- 줄 맨 앞 **✍**는 글쓰기 브리프 복사, 마우스를 올리면 보이는 **`+`**는 할 일로 추가예요.
- 새 키워드의 검색량은 **화면을 먼저 보여준 뒤 뒤에서 채워요** ("검색량을 조회하고 있어요"가 보이는 동안 숫자가 차례로 들어옵니다).

### 블로그 › 키워드 분석

키워드를 넣으면 글감으로 괜찮은지 판단할 정보를 한 번에 보여줍니다.

- **월간 검색량 · 광고 경쟁도 · 검색 추이 · 최근 7일 · 블로그 문서 수 · 포화도**
- **연관어로 돌리기** — 포화도가 `보통`·`높음`인 대표 키워드(예: "절임배추", 문서 62만 개)면, 그 키워드를 품은 연관어 중 **검색량은 적당하고 경쟁 글이 적은 키워드**를 찾아 보여줘요 (예: "절임배추 20kg 몇포기", 월 11,780회·문서 5,280개). 글이 적은 블로그는 대표 키워드로는 상위에 오르기 어려워서, 이 연관어를 메인 키워드로 쓰는 게 조회수에 훨씬 유리해요. 누르면 그 키워드로 다시 분석해요. 복사하는 브리프에도 같은 표가 들어가요.
- **24개월 검색 추이 차트** — 마우스를 올리면 달마다 값이 보여요. `시즌` 키워드면 **`+ 시즌 전 알림`** 으로 시즌 5주 전에 글을 준비하도록 일정에 넣을 수 있어요.
- **실제 질문**(지식iN) · **상위 블로그 글** · **최신 뉴스** · **카페 글** · 장소 검색 결과
- **연관 키워드** 상위 100개 — 누르면 계속 파고들 수 있어요 (예: "국민연금" → "국민연금 수령나이 조회")
- **글쓰기 바**: 유형·구성·플랫폼을 고르고 **✍ 브리프 복사**, 또는 **`+ 할 일`**

| 최근 7일 | 최근 7일 검색 ÷ 그 전 4주 평균 (일간 추이). **2배 이상 `급상승`**, 1.3배 이상 `상승`, 0.7배 이하 `하락`. 지금 뜨는 키워드를 잡는 용도예요 |
| 광고 경쟁도 | 검색광고 입찰 경쟁(낮음·중간·높음)이에요. **블로그 노출 경쟁과는 달라요** — 블로그 경쟁은 문서 수·포화도로 봐요 |
| 검색량 `<10` | 네이버 기준 한 달 10회 미만 |
| 검색량 `-` | 뉴스 제목처럼 긴 문장 키워드라 데이터가 없음 → 짧은 핵심어로 다시 조회해 보세요 |

추이·포화도의 기준은 경험칙이에요. 차트와 숫자를 함께 보면서 참고로 쓰세요.

### 블로그 › 초안

Claude가 저장한 초안을 발행 직전까지 다듬는 화면입니다.

- **상태 (초안 · 발행됨)** — 목록의 각 줄에 상태가 보이고, 위의 탭으로 상태별로 거를 수 있어요. 줄을 누르면 아래로 펼쳐져서 상태를 바꾸고 **글 주소**와 발행 시각을 적을 수 있어요. 예약 발행을 걸어 둔 글도 발행됨으로 바꿔 두면 돼요. 초안 화면 옆 패널의 **상태** 카드에서도 바꿀 수 있어요.
- **목록 순서** — **발행됨이 위, 초안이 아래**이고, 같은 상태끼리는 마지막 수정이 최근인 글부터 보여요. 상태를 바꿔도 펼친 줄이 튀지 않도록 순서는 목록을 새로 열 때 다시 맞춰져요.
- **분량 맞추기** — 초안 글자 수가 범위의 최소(네이버 1,500자)에 몰리지 않도록 플랫폼마다 **목표**(네이버 2,000자, 티스토리 2,500자, Blogger 2,700자)를 두었어요. Claude가 초안을 저장하면 실제 본문 글자 수를 재서 알려 주고, 목표보다 짧으면 바로 보완해 다시 저장해요. 직접 재 보려면 `npm run --silent draft-length -- drafts/파일.md`.
- **발행된 초안은 고치지 않아요** — 발행됨 상태인 초안은 Claude가 고치지 않아요 (`update_draft`가 거부해요). 발행한 글은 다시 쓰지 않으니 토큰을 아끼려는 정책이에요. 발행 전인데 잘못 발행됨으로 표시했다면 상태를 초안으로 바꾼 뒤 고쳐 달라고 하세요.
- **이전·다음 초안 (`‹` `›`)** — 초안 화면 제목 왼쪽의 버튼으로 목록 순서의 앞·뒤 초안으로 바로 넘어가요. 발행됨은 건너뛰고 **초안 상태인 글만** 찾아가서, 아직 손볼 글을 차례로 볼 때 좋아요. 더 없으면 버튼이 흐려져요.
- **작성일로 보기** — 상태 탭 오른쪽의 `작성일` 버튼을 누르면 달력이 열려요. 초안이 있는 날에는 개수가 보이고, 날짜를 누르면 그날 쓴 초안만 보여요. **여러 날을 눌러 함께 볼 수 있고**(다시 누르면 빠져요), 버튼에는 "11월 3일(화) 외 2일"처럼 보여요. 상태 탭과 함께 걸러져요 (예: 11월 3일 + 초안). 고른 날은 **다른 화면에 다녀와도 그대로** 남아 있어요(이 브라우저에 기억). `×`나 `전체 기간`으로 풀어요.
- **칼럼으로 정렬** — 표 머리(키워드·상태·지식iN·플랫폼·작성일·마지막 수정)를 **누른 순서가 정렬 우선순위**예요. 예: 키워드 → 상태 → 작성일 → 마지막 수정 순으로 누르면 키워드가 같을 때 상태로, 상태도 같으면 작성일로 정렬돼요. 같은 머리를 다시 누르면 방향(↑↓)이 바뀌고, 한 번 더 누르면 빠져요. 고른 정렬은 필터 아래에 "정렬 키워드 ↑ › 상태 ↑ › …"로 보이고 **다음에 와도 기억**돼요. `정렬 풀기`를 누르면 기본 순서(발행됨 → 초안, 최근 수정 순)로 돌아가요.
- **프롬프트 바로 복사** — 목록 맨 오른쪽 `프롬프트` 칸의 `복사`를 누르면 그 초안의 **이미지 5장 프롬프트**가 복사돼요. 초안을 열지 않고 바로 Gemini에 붙여넣으면 돼요. 스타일(사진·일러스트)은 초안 화면에서 마지막으로 고른 걸 따라가요 (처음엔 사진).
- **지식iN 답변 준비** — 줄을 펼치면 그 키워드의 지식iN 질문(최신순 20개, 검색어·정렬 변경 가능)이 나와요. 한 번 불러온 목록은 10분 동안 기억해서 접었다 다시 펼치면 바로 보이고, 새 질문을 보고 싶으면 **검색**을 누르면 돼요. 질문의 **답변 쓰기**를 누르면:
  1. `질문 열기 ↗`로 질문을 열어 **본문을 복사해 붙여넣어요** (검색 결과는 앞부분만 줘서, 답변이 질문에 맞으려면 이게 가장 중요해요).
  2. **답변 요청문 복사** → Claude에 붙여넣으면, 질문에 먼저 답하고 내 글의 표·순서 같은 "더 볼 이유"를 들어 글 주소로 한 번 이어 주는 답변이 나와요. 글에 없는 내용은 지어내지 않고, 글로 답하기 어려운 질문이면 **답변 비추천**이라고 알려 줘요. 억지 답변은 안 하느니만 못하니까요.
  3. 답변을 올렸으면 **답변함으로 표시** → 같은 질문에 두 번 답하지 않게 표시되고, 목록에 답변 수가 보여요.
  - 글 주소가 없으면 요청문에 `[글 주소]` 자리로 들어가요. 상태를 발행됨으로 바꾸고 주소를 넣어 두세요.
- **예약 발행 시간** — 사이드 메뉴 맨 아래에 늘 보여요. 조건을 바꾸려면 오른쪽 위 버튼으로 **블로그 › 예약 발행** 화면으로 가요 (아래 설명).

- **미리보기** — 블로그에 올렸을 때 모습 그대로. 사람이 채울 자리는 형광펜으로 표시돼요 (파랑: 이미지, 노랑: 직접 작성, 빨강: 확인 필요).
- **항목별 복사** — 제목 후보, 메타 설명, 태그, 본문, 스레드 홍보글. 글자 수와 권장 분량도 보여줘요.
- **서식 포함 복사 (네이버)** — 본문을 소제목(굵고 크게)·굵은 문장·표가 입혀진 채로 복사해요. 스마트에디터에 붙여넣으면 `■`·`★`를 바꾸고 지우는 손질이 줄어듭니다. 서식이 이상하게 들어오면 **텍스트로 복사**로 예전처럼 붙여넣으세요.
- **발행 전 체크리스트** — 채울 자리를 하나씩 체크.
- **`+ 발행 할 일`** — 남은 자리가 하위 할 일로 들어간 할 일을 만들어요. 만든 뒤에는 `✓ 할 일 #N`으로 바뀝니다.
- **썸네일 만들기** — 다른 화면으로 넘어가지 않고 **초안 화면 안에서** 썸네일 칸이 펼쳐져요 (미리보기 아래). 추천 제목이 채워져 있고, PNG 다운로드·이미지 복사를 바로 할 수 있어요. 접었다 펴도 고친 내용은 남아요.
- **태그 전체 복사** — 태그를 한 번에 복사해요. 네이버 초안은 보이는 그대로(`#태그 #태그`), 티스토리·Blogger는 태그 칸에 맞게 쉼표로 이어서 복사해요.
- **이미지 5장 프롬프트** — 이 글의 본문 이미지 5장을 한 번에 만들어 달라는 요청문을 복사해 **Gemini에 그대로 붙여넣어요**. 사진·일러스트 중에 고르고, 이미지 속 글자나 가짜 화면·표는 만들지 않게 해 둡니다. 초안은 늘 **대표 썸네일 1개(본문 첫 줄) + 본문 이미지 5개**예요. 대표 썸네일은 **썸네일 만들기**로 직접 만들고(`추천: 썸네일 만들기`), 본문 이미지는 모두 AI로 만들 장면(`추천: AI 생성`)이라 프롬프트의 **1~5번이 본문 이미지 1~5번 자리**에 적힌 장면 그대로예요. 만든 이미지를 순서대로 초안의 자리에 넣으면 되고, 직접 캡처하거나 만들 이미지는 없어요 (상품 사용기·방문기는 실제 사진이 필요해서 예외). 크롬 확장의 **이미지 모음**을 열어 두면 Gemini에서 만든 이미지가 저절로 모여요.

### 블로그 › 예약 발행

뽑은 시간은 **사이드 메뉴 맨 아래에 늘 보여요.** 초안을 쓰다가도 화면을 옮기지 않고 바로 확인할 수 있어요.

- **사이드 메뉴의 시간** — 다음에 걸 예약은 강조색, 이미 지난 시간은 줄을 그어 보여 줘요(1분마다 갱신). **시간을 누르면 그 시각이 복사**돼요. `다시 뽑기`를 누르면 같은 조건(바로 올린 시각·개수·간격)으로 새로 뽑고, `지금부터`를 누르면 바로 올린 시각만 지금(다음 10분 단위)으로 바꿔 개수·간격은 그대로 새로 뽑아요. 조건을 바꾸려면 메뉴의 **예약 발행** 화면에서 바꿔요.

- 하나는 바로 올리고 나머지를 예약할 때 써요. **바로 올린 시각** 뒤로 **간격(기본 3~4시간) 안의 랜덤 시간**을 4개(1~8개 중 선택) 뽑아 줘요. 간격은 1~8시간 중에서 최소·최대를 고를 수 있어요. 예약 발행 칸에 맞게 10분 단위이고, 자정을 넘기면 다음 날 날짜로 보여요. 뽑힌 시간은 한 줄의 칩으로 보이고, **칩을 누르면 그 시각(예: 22:10)이 복사**돼요. 칩에 마우스를 올리면 앞 시간과의 간격이 보여요. `다시 뽑기`, `전체 복사`도 있어요.
- **뽑은 시간은 기억돼요.** 새로고침하거나 다른 화면에 갔다 와도 같은 시간이 그대로 보여서, 예약을 걸다가 다시 확인할 수 있어요. 날짜가 지나면 새로 뽑아요.
- `지금부터` — 바로 올린 시각을 지금(다음 10분 단위)으로 바꾸고 다시 뽑아요.

### 블로그 › 썸네일

제목만 넣으면 블로그 대표 이미지를 만들어 줍니다.

- `*단어*`로 감싸면 그 부분이 **강조색**, 긴 제목은 알아서 줄바꿈하고 크기를 맞춰요.
- 템플릿 4종 · 크기 3종(티스토리·Blogger 1200×630, 네이버·스레드 1080×1080, 16:9) · 한글 글꼴 3종 · 색 조합 6종(직접 지정 가능) · **랜덤 조합** 버튼(누를 때마다 글자가 잘 읽히는 어울리는 색을 새로 뽑아요. 마음에 드는 게 나오면 그대로 쓰면 기억돼요)

### 블로그 › 작성 가이드

**네이버 · 티스토리 · Blogger**에 글을 올리는 순서를 단계별로 보고 따라 할 수 있어요.

- **발행 따라하기** — 초안 복사부터 에디터 모드 바꾸기, 사진·태그 넣기, 발행 후 확인까지
- **수익과 직결되는 것** — 애드포스트·애드센스 연결, 검색 등록, 플랫폼별로 유입이 생기는 방식
- **품질 팁**과 **하지 말 것** — 계정 정지로 이어지는 무효 클릭, 복사, 대량 생산 글
- **공통** 탭에는 광고 수익이 어떻게 계산되는지(방문 수 × 클릭률 × 클릭 단가)와 발행 전 품질 체크가 있어요.
- **수익 승인** 탭에는 애드포스트·애드센스·쿠팡 파트너스 승인을 받기까지의 순서와 프로그램별 기준이 있어요. 공개되지 않은 기준("90일·50개·100명" 같은 숫자)은 속설이라고 구분해 두었어요.

초안 화면의 붙여넣기 안내에 있는 **발행 순서 전체 보기**를 누르면 그 초안 플랫폼의 가이드로 바로 갑니다.

- 아래에 **훅 공식 26가지**(틀·예·자막·잘 맞을 때·망치는 법)가 있어요. 틀 옆 **복사**로 바로 가져다 쓰세요.

### 인스타 › 캡션 점검

캡션을 붙여넣으면 피드에 보이는 부분과 점검 결과가 바로 나와요. 검색어를 넣으면 문장 속에 들어 있는지도 확인합니다 (인스타 검색은 해시태그보다 캡션 문장을 읽어요).

## Claude와 글쓰기

toolhub가 데이터를 모아 주면, 판단과 글쓰기는 Claude가 합니다. 편한 방법을 고르세요.

### 방법 1. Claude 데스크톱 앱에서 대화로 (추천)

[데스크톱 앱 연결](#4-claude-데스크톱-앱-연결하기-선택-추천)을 해 두면 복사·붙여넣기 없이 말로 시킬 수 있어요.

```
오늘 뜬 키워드로 오늘 쓸 글 5개 골라줘                 → 지금 뜨는 이슈(반짝 이슈 포함)를 최근 7일·포화도로 골라, 경쟁 센 건 연관어로 돌려 줌
절임배추로 네이버 글 써줘                              → 경쟁이 세면 연관어(예: 절임배추 20kg 몇포기)로 돌려서 씀
(캡처 붙여넣고) 이 화면 키워드들 분석해서 골라줘          → 화면 속 키워드를 한 번에 조회해 표로 비교
2번으로 네이버 글 써줘                                → 같은 키워드로 쓴 초안이 있는지 먼저 확인해 줌
저장하고 웹에서 열어줘                                → 초안 화면에서 미리보기·복사
어제 쓴 국민연금 글 도입부를 더 짧게 고쳐줘              → 고친 뒤 같은 파일에 저장 (이전 버전은 보관)
이 글 발행을 내일 오후 3시 할 일로 잡아줘
이번 주 할 일 보여줘 / 5번 완료 / 17번에 하위 할 일 추가해줘
toolhub 웹 열어줘 / 캘린더 열어줘 / 웹 서버 꺼줘
```

### 방법 2. 브리프를 복사해서 claude.ai에 붙여넣기

1. claude.ai에 프로젝트를 하나 만들고, [project-instructions.md](docs/prompts/project-instructions.md) 내용을 **지침**에, `docs/prompts/`의 나머지 파일들을 **지식**에 올립니다 (처음 한 번).
2. **키워드 분석**(또는 키워드 기록의 ✍)에서 **브리프 복사** → 프로젝트 대화창에 붙여넣기.

> 프롬프트 파일을 고치면 claude.ai 프로젝트에도 다시 올려 주세요.

### 방법 3. Claude Code에서 명령 한 줄

이 폴더에서 Claude Code를 열고:

```
/blog-draft 국민연금 수령나이 티스토리
/blog-draft 에어프라이어 리뷰 네이버
/blog-draft 성수동 브런치 카페 장소, 제주 아이와 가볼만한곳 장소 티스토리
```

초안이 `drafts/` 폴더에 저장되고, 웹의 **초안** 화면에서 바로 열 수 있어요.

### 초안을 고를 때 쓰는 옵션

| 옵션 | 고를 수 있는 것 |
|---|---|
| 플랫폼 | **티스토리**(HTML) · **Blogger**(HTML·검색 설명·퍼머링크) · **네이버**(스마트에디터용 텍스트) |
| 유형 | **정보**(제도·방법·비교) · **리뷰**(상품·서비스 사용기) · **장소**(맛집·여행지 방문기) |
| 구성 | 자동(글마다 무작위) 또는 직접 선택 — 정보: 질문 답변형·결론 먼저형·상황으로 시작형·비교표 중심형 / 리뷰: 요약 먼저형·사용 기간 순·장단점 중심형·비교형 / 장소: 정보 먼저형·방문 동선 순·추천 포인트형·상황별 가이드 |

글마다 구성이 달라지고 "오늘은 ~에 대해 알아보겠습니다" 같은 상투구를 피하도록 해 두어서, 글이 쌓여도 같은 틀로 찍어낸 느낌이 나지 않아요.

### 발행 전에 꼭

초안 본문에는 **이미지 자리**만 표시돼 있고, 나머지는 복사해서 바로 올릴 수 있게 완성돼 있어요. 덧붙이면 좋은 경험과 확인할 내용은 본문 밖 **사람이 할 일**에 정리돼요. **AI 초안을 그대로 발행하지 마세요** — 검색 엔진과 애드센스는 사람이 다듬고 경험이 담긴 글을 더 좋게 평가합니다.

| 표시 | 할 일 |
|---|---|
| `[이미지: …]` | 직접 캡처·촬영한 사진을 넣어요 (뉴스 사진·검색 이미지는 저작권 문제로 쓰면 안 돼요) |
| 사람이 할 일 › 덧붙일 경험 | 적힌 소제목 아래에 내 경험이나 의견을 써요 (리뷰·장소 글은 필수) |
| 사람이 할 일 › 확인할 내용 | 공식 출처에서 확인하고 필요하면 고쳐요 |

예전 초안에 남아 있는 `[직접 작성: …]`·`[확인 필요: …]` 표시도 미리보기·체크리스트에서 그대로 보여요.

## 자주 묻는 질문

**비용이 드나요?**
아니요. 네이버 검색광고 API와 NAVER API HUB는 무료로 쓸 수 있고(API HUB는 현재 한시적 무료, 유료 전환 시 사전 공지), 썸네일도 내 PC에서 그려서 비용이 없어요. 글쓰기는 쓰고 있는 Claude 구독 안에서 합니다.

**데이터는 어디에 저장되나요?**
이 폴더의 `data/`(키워드 기록·할 일)와 `drafts/`(초안)에만 있어요. git에 올라가지 않으니 필요하면 직접 백업해 두세요.

**웹을 꼭 켜 둬야 하나요?**
아니요. Claude 데스크톱 앱은 웹 없이도 할 일·키워드·초안을 다룰 수 있어요. 화면이 필요하면 "toolhub 웹 열어줘"라고 하면 알아서 켜서 열어 줍니다 (http://localhost:3100).

**키워드가 왜 하루 종일 쌓이지 않나요?**
실시간 키워드는 **실시간 화면을 열 때**(또는 Claude에게 실시간 키워드를 물을 때) 기록돼요. 자주 열어볼수록 많이 쌓입니다.

**어떤 소스가 "조회 실패"로 나와요.**
네이트·signal.bz는 공식 API가 아니라서 사이트가 바뀌면 그 소스만 실패할 수 있어요. 나머지는 그대로 동작합니다.

**네이버 크리에이터 어드바이저의 트렌드도 볼 수 있나요?**
크리에이터 어드바이저는 공개 API가 없어서 toolhub가 직접 가져오지는 못해요. 대신 두 가지로 비슷하게 봐요.

- **캡처 붙여넣기 (가장 정확)** — 트렌드 화면(검색 유입 트렌드·메인 유입 트렌드·주제별 트렌드)을 **캡처해서 Claude 데스크톱 앱에 붙여넣으면**, Claude가 키워드를 읽어 toolhub로 검색량·추이·최근 7일·포화도를 한 번에 조회하고, 경쟁이 센 키워드는 연관어로 돌려서 제안해요. 이미 초안을 쓴 키워드도 표시돼요. 한 번에 50개까지 돼요.
- **최근 7일 (검색 유입 트렌드 대용)** — 네이버 데이터랩 일간 추이로 최근 7일이 그 전 4주보다 얼마나 늘었는지 계산해요. 키워드 분석·키워드 찾기·브리프에 `급상승 ×2.4`처럼 나와요. 다만 "분야별로 뜨는 검색어 목록"을 주는 API는 없어서, 후보는 실시간 키워드·연관어에서 와요.
- **메인 유입 트렌드(홈판)**는 대신할 공개 API가 없어요. 캡처로 봐 주세요.

**네이버 블로그 수익은 어떻게 내나요?**
네이버 블로그는 애드센스를 붙일 수 없고 **애드포스트**로 수익을 냅니다. 티스토리·Blogger는 애드센스를 씁니다. toolhub는 어느 쪽이든 글감 찾기와 초안 쓰기를 같은 방식으로 도와요.

**상품 가격도 볼 수 있나요?**
네이버 쇼핑 검색 API가 종료돼서 가격·상품 목록은 볼 수 없어요. 쇼핑 인사이트로 상품 키워드의 **관심 추이**는 볼 수 있습니다 (Claude에게 "에어프라이어 쇼핑 트렌드 보여줘").
