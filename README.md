# toolhub

**할 일 관리와 블로그 운영을 한곳에서.** 내 맥에서 돌아가는 개인 업무 도구입니다.

오늘 할 일을 정리하고, 지금 뜨는 키워드에서 글감을 찾고, Claude와 함께 초안을 쓰고, 썸네일까지 만들어 발행 준비를 끝낼 수 있습니다. Claude 데스크톱 앱과 연결하면 이 모든 걸 **대화로** 시킬 수도 있어요.

- 💸 **무료**: 쓰는 서비스(네이버 API 등)가 모두 무료이고, 비용이 드는 AI API도 쓰지 않습니다.
- 🔒 **내 PC에만**: 할 일·키워드 기록·초안은 이 맥의 `data/`, `drafts/` 폴더에만 저장됩니다.

## 이런 걸 할 수 있어요

### ✅ 할 일을 말하듯이 적고, 한눈에 관리하기

```
내일 오후 3시 국민연금 글 발행 #블로그 @블로그 운영 !높음 매주
```

이렇게 한 줄만 쓰면 **날짜·시간·태그·프로젝트·우선순위·반복**이 알아서 정리됩니다. 오늘 할 일, 다음 7일, 칸반 보드, 월간 캘린더로 보고, 끌어다 놓아서 상태나 날짜를 바꿀 수 있어요. 반복 할 일은 끝내면 다음 회차가 저절로 생깁니다.

### 🔥 지금 뜨는 키워드에서 "쓸 만한 글감" 찾기

Google Trends·네이트·signal.bz의 실시간 키워드를 모아 날짜별로 쌓아 두고, 키워드마다 이런 걸 보여줍니다.

- **네이버 월간 검색량과 경쟁도** — 많이 찾는데 경쟁이 약한 키워드는?
- **24개월 검색 추이** — 매년 돌아오는 시즌 키워드인지, 반짝 이슈인지
- **포화도** — 검색량에 비해 이미 글이 너무 많지는 않은지
- **사람들이 실제로 묻는 질문**(지식iN), **이미 상위에 있는 블로그 글**, 최신 뉴스, 카페 후기
- **며칠째 계속 뜨는 키워드**인지 (반짝 이슈가 아니라 관심이 이어지는 주제)

다른 곳에서 본 키워드도 됩니다. 네이버 **크리에이터 어드바이저**의 트렌드 화면을 캡처해 Claude 데스크톱 앱에 붙여넣고 "이 키워드들 분석해서 쓸 만한 거 골라줘"라고 하면, 화면 속 키워드를 **한 번에** 조회해 글이 적은 키워드부터 표로 보여줍니다.

### ✍️ 키워드 하나로 블로그 초안 받기

고른 키워드로 Claude에게 초안을 받습니다. 검색량·연관 키워드·실제 질문·상위 글을 담은 **브리프**가 자동으로 만들어져서, 검색자가 궁금해하는 걸 짚으면서 기존 글과 겹치지 않는 초안이 나옵니다.

- **티스토리·Blogger·네이버** 형식을 골라서 받고
- **정보 글·리뷰·장소(맛집·여행)** 유형마다 맞는 구조로
- 글마다 **구성이 달라지고 AI 특유의 상투구를 피해서**, 찍어낸 듯한 글이 되지 않게
- 내 경험을 넣을 자리, 사진을 넣을 자리, 사실 확인이 필요한 곳을 **표시해 줍니다**

### 🚀 발행 준비를 한 화면에서

초안을 열면 블로그에 올렸을 때 모습으로 **미리보기**하고, 제목·태그·본문·스레드 홍보글을 **버튼 하나로 복사**하고, 남은 할 일(사진·경험·확인)을 **체크리스트**로 챙깁니다. **썸네일**도 제목만 넣으면 PNG로 만들어 줍니다.

### 🔗 글감과 일정을 바로 연결

키워드나 초안 옆의 **`+ 할 일`** 을 누르면 문장이 미리 채워진 입력창이 열리고, Enter 한 번이면 일정에 들어갑니다.

- "국민연금 수령나이 글 쓰기 내일" — 키워드 분석 링크가 붙은 할 일
- "국민연금 수령나이 글 발행" — 초안의 남은 자리(사진·경험·확인)가 **하위 할 일로** 들어간 할 일
- "연말정산 시즌 글 준비" — **시즌 5주 전**으로 날짜가 잡힌 알림

### 💬 Claude 데스크톱 앱에서 대화로

```
오늘 할 일 보여줘
오늘 뜬 키워드 중에 블로그로 쓸 만한 거 3개 골라줘
(캡처 붙여넣고) 이 화면 키워드들 분석해줘
2번으로 네이버 리뷰 글 써서 저장해줘
이 글 발행을 내일 오후 할 일로 잡아줘
캘린더 열어줘
```

## 시작하기

### 1. 설치하고 실행하기

[Node.js](https://nodejs.org) 24 이상이 필요합니다.

```bash
npm install
npm run web
```

브라우저에서 http://localhost:3000 을 열면 첫 화면(일정 관리 › 오늘)이 나옵니다. 여기까지만 해도 **일정 관리와 실시간 키워드**는 바로 쓸 수 있어요.

### 2. 네이버 키 넣기 (선택, 무료)

키를 넣을수록 글감 판단에 쓸 정보가 늘어납니다. 없어도 해당 정보만 빠지고 나머지는 그대로 동작해요.

```bash
cp apps/web/.env.example apps/web/.env.local   # 이 파일에 키를 적습니다 (git에 올라가지 않아요)
```

**① 네이버 검색광고 API** → 월간 검색량·경쟁도·연관 키워드

1. [searchad.naver.com](https://searchad.naver.com)에 가입합니다 (네이버 아이디로 가능, 개인도 사업자등록 없이 가능, 광고비 없이 무료).
2. 광고 시스템 → **도구 → API 사용 관리**에서 키 세 개를 발급받아 적습니다.

```ini
NAVER_SEARCHAD_API_KEY=액세스 라이선스
NAVER_SEARCHAD_SECRET_KEY=비밀키
NAVER_SEARCHAD_CUSTOMER_ID=CUSTOMER_ID
```

**② NAVER API HUB** → 검색 추이·포화도·실제 질문·상위 블로그 글·뉴스·카페 글·장소 정보·쇼핑 트렌드

1. [네이버 클라우드 플랫폼](https://www.ncloud.com)에 가입하고 콘솔에 로그인합니다.
2. **Menu → All Services → Application Services → NAVER API HUB → Application 등록**
3. API는 **검색어 트렌드, 쇼핑 인사이트, 블로그·지식iN·뉴스·카페글·지역 검색**을 고릅니다.
4. **API 관리 → 인증 정보**의 Client ID·Secret을 적습니다.

```ini
NAVER_API_HUB_CLIENT_ID=Client ID
NAVER_API_HUB_CLIENT_SECRET=Client Secret
```

키를 바꾼 뒤에는 웹 서버를 다시 켜 주세요.

### 3. 내 블로그 정보 적기

[docs/prompts/project-instructions.md](docs/prompts/project-instructions.md)의 **"내 블로그 정보"** `[ ]` 부분(주제·독자·말투·관점·플랫폼)을 채워 두세요. 초안의 말투와 관점이 여기서 정해집니다.

### 4. Claude 데스크톱 앱 연결하기 (선택, 추천)

대화로 할 일을 관리하고 글을 쓰려면 데스크톱 앱에 toolhub를 연결합니다.

1. 터미널에서 `which node`(예: `/usr/local/bin/node`)와, 이 폴더에서 `pwd`(예: `/Users/me/source/toolhub`)를 확인합니다.
2. `~/Library/Application Support/Claude/claude_desktop_config.json`의 `mcpServers`에 추가합니다 (경로는 1번 값으로, 반드시 절대 경로).

   ```json
   {
     "mcpServers": {
       "toolhub": {
         "command": "/usr/local/bin/node",
         "args": [
           "--env-file-if-exists=/Users/me/source/toolhub/apps/web/.env.local",
           "/Users/me/source/toolhub/packages/mcp/src/server.ts"
         ]
       }
     }
   }
   ```

3. 데스크톱 앱을 **완전히 종료(⌘Q)했다가 다시 실행**하면 도구 메뉴에 `toolhub`가 보입니다.

> Claude Code에서는 이 폴더를 열기만 하면 자동으로 연결됩니다 (`.mcp.json`).

## 화면 안내

왼쪽 사이드바에서 메뉴를 고릅니다. 좁은 화면에서는 왼쪽 위 ☰ 버튼을 누르세요.

### 일정 관리

**빠른 추가** — 맨 위 입력창에 한 줄로 적습니다. 입력하는 동안 어떻게 알아들었는지 칩으로 미리 보여줘요. 어느 화면에서든 **`C`** 키를 누르면 바로 입력할 수 있습니다.

| 이렇게 쓰면 | 예 |
|---|---|
| 날짜 | `오늘` `내일` `모레` `월요일` `이번 주 금요일` `다음 주 월요일` `주말` `11월 3일` `11/3` `3일 뒤` |
| 시간 | `오전 9시` `오후 3시 30분` `3시반` `15:30` (시간만 쓰면 오늘) |
| 우선순위 | `!긴급` `!높음` `!보통` `!낮음` |
| 태그 | `#블로그` (여러 개 가능) |
| 프로젝트 | `@블로그 운영` — 있는 프로젝트는 띄어쓰기가 있어도 알아듣고, 없는 이름이면 새로 만들어요 (새 이름은 띄어쓰기 없이) |
| 반복 | `매일` `매주` `매월` `매년` |

보고 있는 화면에 맞춰 알아서 채워 주기도 해요. **오늘** 화면에서 날짜 없이 쓰면 오늘, **프로젝트** 화면에서는 그 프로젝트, **캘린더**에서 날짜를 누른 뒤에는 그 날짜로 들어갑니다.

**보기**

| 메뉴 | 보이는 것 |
|---|---|
| 오늘 | 오늘 할 일 + 지난 일정 (숫자가 빨간색이면 밀린 일이 있다는 뜻) |
| 다음 7일 · 전체 | 지난 일정 / 오늘 / 내일 / 7일 안 / 나중 / 날짜 없음으로 묶어서 |
| 날짜 없음 | 언젠가 할 일 모음 |
| 보드 | 할 일 · 진행 중 · 완료 · 취소 칸. **카드를 끌어서** 상태를 바꿔요 |
| 캘린더 | 월간 달력. **날짜를 누르면** 그날로 추가, **할 일을 끌면** 날짜가 바뀌어요 |
| 완료됨 | 끝낸 일 |
| 프로젝트 · 태그 | 그것만 모아 보기 (프로젝트는 이름 바꾸기·삭제 가능, 지워도 할 일은 남아요) |

**할 일 다루기**

- 왼쪽 **동그라미**를 누르면 완료. 테두리 색은 우선순위(빨강 긴급 · 주황 높음 · 노랑 보통 · 보라 낮음), 반쯤 찬 동그라미는 진행 중이에요.
- 할 일을 누르면 오른쪽에 **상세 패널**이 열려요. 상태·마감일·반복·프로젝트·태그·하위 할 일·메모·링크를 고치면 바로 저장되고, `Esc`로 닫습니다.
- **반복 할 일**을 끝내면 완료 기록은 남고 다음 회차가 새로 생겨요.
- Claude 데스크톱 앱에서 바꾼 내용도 화면에 자동으로 반영돼요.

### 블로그 › 실시간

Google Trends · 네이트 · signal.bz의 **지금 순위**를 한 화면에서 봅니다. `NEW`는 새로 진입, `▲▼`는 순위 변동, 숫자는 구글 검색량(대략)이에요.

> 이 화면을 **열 때마다 처음 보는 키워드가 그날 기록에 쌓입니다.** 하루에 자주 들여다볼수록 그날 뜬 키워드를 빠짐없이 모을 수 있어요.

### 블로그 › 키워드 기록

그날(또는 최근 7일·30일) 뜬 키워드를 표로 봅니다.

- **검색량 순**으로 정렬하면 많이 찾는 키워드가 위로 와요. **경쟁도**가 낮을수록 글감으로 좋습니다.
- 7일·30일 보기에서는 **등장 일수**를 보여줘요. `지속`(3일 이상) 키워드는 반짝 이슈가 아니라 관심이 이어지는 주제라 눈여겨볼 만해요.
- 이미 초안을 쓴 키워드에는 **✓**가 붙어서 같은 주제로 두 번 쓰지 않게 해 줍니다.
- 줄 맨 앞 **✍**는 글쓰기 브리프 복사, 마우스를 올리면 보이는 **`+`**는 할 일로 추가예요.
- 새 키워드의 검색량은 **화면을 먼저 보여준 뒤 뒤에서 채워요** ("검색량을 조회하고 있어요"가 보이는 동안 숫자가 차례로 들어옵니다).

### 블로그 › 키워드 분석

키워드를 넣으면 글감으로 괜찮은지 판단할 정보를 한 번에 보여줍니다.

- **월간 검색량 · 경쟁도 · 검색 추이 · 블로그 문서 수 · 포화도**
- **24개월 검색 추이 차트** — 마우스를 올리면 달마다 값이 보여요. `시즌` 키워드면 **`+ 시즌 전 알림`** 으로 시즌 5주 전에 글을 준비하도록 일정에 넣을 수 있어요.
- **실제 질문**(지식iN) · **상위 블로그 글** · **최신 뉴스** · **카페 글** · 장소 검색 결과
- **연관 키워드** 상위 100개 — 누르면 계속 파고들 수 있어요 (예: "국민연금" → "국민연금 수령나이 조회")
- **글쓰기 바**: 유형·구성·플랫폼을 고르고 **✍ 브리프 복사**, 또는 **`+ 할 일`**

| 포화도 | 블로그 문서 수 ÷ 월간 검색량. **10배 이하 `기회`**, 50배 이하 `보통`, 그 이상 `높음`. 예: 국민연금 수령나이 2배, 에어프라이어 추천 67배, 다이어트 800배 |
| 검색량 `<10` | 네이버 기준 한 달 10회 미만 |
| 검색량 `-` | 뉴스 제목처럼 긴 문장 키워드라 데이터가 없음 → 짧은 핵심어로 다시 조회해 보세요 |

추이·포화도의 기준은 경험칙이에요. 차트와 숫자를 함께 보면서 참고로 쓰세요.
</details>

### 블로그 › 초안

Claude가 저장한 초안을 발행 직전까지 다듬는 화면입니다.

- **미리보기** — 블로그에 올렸을 때 모습 그대로. 사람이 채울 자리는 형광펜으로 표시돼요 (파랑: 이미지, 노랑: 직접 작성, 빨강: 확인 필요).
- **항목별 복사** — 제목 후보, 메타 설명, 태그, 본문, 스레드 홍보글. 글자 수와 권장 분량도 보여줘요.
- **발행 전 체크리스트** — 채울 자리를 하나씩 체크.
- **`+ 발행 할 일`** — 남은 자리가 하위 할 일로 들어간 할 일을 만들어요. 만든 뒤에는 `✓ 할 일 #N`으로 바뀝니다.
- **썸네일 만들기** — 추천 제목이 채워진 채로 썸네일 화면이 열려요.

### 블로그 › 썸네일

제목만 넣으면 블로그 대표 이미지를 만들어 줍니다.

- `*단어*`로 감싸면 그 부분이 **강조색**, 긴 제목은 알아서 줄바꿈하고 크기를 맞춰요.
- 템플릿 4종 · 크기 3종(티스토리·Blogger 1200×630, 네이버·스레드 1080×1080, 16:9) · 한글 글꼴 3종 · 색 조합 6종(직접 지정 가능)
- **PNG 다운로드** 또는 **이미지 복사**(에디터에 바로 붙여넣기)
- 블로그 이름·템플릿·색·글꼴은 기억돼서 **썸네일 스타일이 저절로 통일**돼요.

## Claude와 글쓰기

toolhub가 데이터를 모아 주면, 판단과 글쓰기는 Claude가 합니다. 편한 방법을 고르세요.

### 방법 1. Claude 데스크톱 앱에서 대화로 (추천)

[데스크톱 앱 연결](#4-claude-데스크톱-앱-연결하기-선택-추천)을 해 두면 복사·붙여넣기 없이 말로 시킬 수 있어요.

```
오늘 뜬 키워드 중에 블로그로 쓸 만한 거 3개 골라줘      → 검색량·추이·포화도를 보고 골라 줌
(캡처 붙여넣고) 이 화면 키워드들 분석해서 골라줘          → 화면 속 키워드를 한 번에 조회해 표로 비교
2번으로 네이버 글 써줘                                → 같은 키워드로 쓴 초안이 있는지 먼저 확인해 줌
저장하고 웹에서 열어줘                                → 초안 화면에서 미리보기·복사
어제 쓴 국민연금 글 도입부를 더 짧게 고쳐줘              → 고친 뒤 같은 파일에 저장 (이전 버전은 보관)
이 글 발행을 내일 오후 3시 할 일로 잡아줘
이번 주 할 일 보여줘 / 5번 완료 / 17번에 하위 할 일 추가해줘
toolhub 웹 열어줘 / 캘린더 열어줘 / 웹 서버 꺼줘
```

### 방법 2. 브리프를 복사해서 claude.ai에 붙여넣기

1. claude.ai에 프로젝트를 하나 만들고, [project-instructions.md](docs/prompts/project-instructions.md) 내용을 **지침**에, `docs/prompts/`의 나머지 파일들을 **지식**에 올립니다 (처음 한 번).
2. **키워드 분석**(또는 키워드 기록의 ✍)에서 **브리프 복사** → 프로젝트 대화창에 붙여넣기.

> 프롬프트 파일을 고치면 claude.ai 프로젝트에도 다시 올려 주세요.

### 방법 3. Claude Code에서 명령 한 줄

이 폴더에서 Claude Code를 열고:

```
/blog-draft 국민연금 수령나이 티스토리
/blog-draft 에어프라이어 리뷰 네이버
/blog-draft 성수동 브런치 카페 장소, 제주 아이와 가볼만한곳 장소 티스토리
```

초안이 `drafts/` 폴더에 저장되고, 웹의 **초안** 화면에서 바로 열 수 있어요.

### 초안을 고를 때 쓰는 옵션

| 옵션 | 고를 수 있는 것 |
|---|---|
| 플랫폼 | **티스토리**(HTML) · **Blogger**(HTML·검색 설명·퍼머링크) · **네이버**(스마트에디터용 텍스트) |
| 유형 | **정보**(제도·방법·비교) · **리뷰**(상품·서비스 사용기) · **장소**(맛집·여행지 방문기) |
| 구성 | 자동(글마다 무작위) 또는 직접 선택 — 정보: 질문 답변형·결론 먼저형·상황으로 시작형·비교표 중심형 / 리뷰: 요약 먼저형·사용 기간 순·장단점 중심형·비교형 / 장소: 정보 먼저형·방문 동선 순·추천 포인트형·상황별 가이드 |

글마다 구성이 달라지고 "오늘은 ~에 대해 알아보겠습니다" 같은 상투구를 피하도록 해 두어서, 글이 쌓여도 같은 틀로 찍어낸 느낌이 나지 않아요.

### 발행 전에 꼭

초안에는 **사람이 채울 자리**가 표시돼 있어요. **AI 초안을 그대로 발행하지 마세요** — 검색 엔진과 애드센스는 사람이 다듬고 경험이 담긴 글을 더 좋게 평가합니다.

| 표시 | 할 일 |
|---|---|
| `[이미지: …]` | 직접 캡처·촬영한 사진을 넣어요 (뉴스 사진·검색 이미지는 저작권 문제로 쓰면 안 돼요) |
| `[직접 작성: …]` | 내 경험이나 의견을 써요 (리뷰·장소 글은 특히 중요) |
| `[확인 필요: …]` | 공식 출처에서 확인하고 고치거나 지워요 |

## 자주 묻는 질문

**비용이 드나요?**
아니요. 네이버 검색광고 API와 NAVER API HUB는 무료로 쓸 수 있고(API HUB는 현재 한시적 무료, 유료 전환 시 사전 공지), 썸네일도 내 PC에서 그려서 비용이 없어요. 글쓰기는 쓰고 있는 Claude 구독 안에서 합니다.

**데이터는 어디에 저장되나요?**
이 폴더의 `data/`(키워드 기록·할 일)와 `drafts/`(초안)에만 있어요. git에 올라가지 않으니 필요하면 직접 백업해 두세요.

**웹을 꼭 켜 둬야 하나요?**
아니요. Claude 데스크톱 앱은 웹 없이도 할 일·키워드·초안을 다룰 수 있어요. 화면이 필요하면 "toolhub 웹 열어줘"라고 하면 알아서 켜서 열어 줍니다 (http://localhost:3100).

**키워드가 왜 하루 종일 쌓이지 않나요?**
실시간 키워드는 **실시간 화면을 열 때**(또는 Claude에게 실시간 키워드를 물을 때) 기록돼요. 자주 열어볼수록 많이 쌓입니다.

**어떤 소스가 "조회 실패"로 나와요.**
네이트·signal.bz는 공식 API가 아니라서 사이트가 바뀌면 그 소스만 실패할 수 있어요. 나머지는 그대로 동작합니다.

**네이버 크리에이터 어드바이저의 트렌드도 볼 수 있나요?**
크리에이터 어드바이저는 공개 API가 없어서 toolhub가 직접 가져오지는 못해요. 대신 트렌드 화면(검색 유입 트렌드·주제별 트렌드 등)을 **캡처해서 Claude 데스크톱 앱에 붙여넣으면**, Claude가 키워드를 읽어 toolhub로 검색량·경쟁도·추이·포화도를 한 번에 조회해 줍니다. 이미 초안을 쓴 키워드도 표시돼요. 한 번에 50개까지 돼요.

**네이버 블로그 수익은 어떻게 내나요?**
네이버 블로그는 애드센스를 붙일 수 없고 **애드포스트**로 수익을 냅니다. 티스토리·Blogger는 애드센스를 씁니다. toolhub는 어느 쪽이든 글감 찾기와 초안 쓰기를 같은 방식으로 도와요.

**상품 가격도 볼 수 있나요?**
네이버 쇼핑 검색 API가 종료돼서 가격·상품 목록은 볼 수 없어요. 쇼핑 인사이트로 상품 키워드의 **관심 추이**는 볼 수 있습니다 (Claude에게 "에어프라이어 쇼핑 트렌드 보여줘").
